# 贪心算法
## 策略
依旧计算前缀和,但在计算前缀和中
+ 使用sum记录当前一段前缀和
	+ 当sum>=0时,表明sum对后面数的前缀和有正贡献
		继续让sum向后记录前缀和
	+ 当sum<0时,表明sum将对后面数的前缀和有负贡献
		让sum停止向后记录,同时比较与上一段正贡献sum
		最大的sum的部分,就是最大子段和

## 思考
+ 如何求出以a[i]为结尾的最大的子段和
	1. 从前先后遍历,以每个前方子段和 对 以a[i]为结尾的最长字段和贡献划分
	2. 减去距离a[i]前的 最小子段和
	3. 得出以a[i]为结尾的最大的子段和
	4. 没向后迭代,更新最小子段和
```c++
 #include<iostream>
using namespace std;
const int N = 2 * 10e5 + 10;
long long arr[N] = { 0 };
int main() {
	int n; cin >> n;
	
	for (int i = 1; i <= n; i++) cin >> arr[i];
	//填入数据
	for (int i = 1; i <= n; i++) arr[i] += arr[i - 1];
	//计算前缀和
	long long ret = -1e20;
	//记录最大子段和
	long long prve = 0;
	//记录ret前的最小前缀和
	for (int i = 1; i <= n; i++)
	{
		ret = max(ret, arr[i] - prve);
		//以arr[i]为结尾的最大子段和
		//应是arr[i]和中去掉arr[i]前的的最小子段和
		prve = min(prve, arr[i]);
		//更新arr[i]前的最小子段和
	}
	cout << ret << endl;
	return 0;
}
```
