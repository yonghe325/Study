# 题目描述
给你三个整数 $a,b,p$，求 $a^b \bmod p$。
## 输入格式
输入只有一行三个整数，分别代表 $a,b,p$。
## 输出格式
输出一行一个字符串 `a^b mod p=s`，其中 $a,b,p$ 分别为题目给定的值， $s$ 为运算结果。
## 输入输出样例 #1
### 输入 #1
```
2 10 9
```
### 输出 #1
```
2^10 mod 9=7
```
## 说明/提示
**样例解释**
$2^{10} = 1024$，$1024 \bmod 9 = 7$。
**数据规模与约定**
对于 $100\%$ 的数据，保证 $0\le a,b < 2^{31}$，$a+b>0$，$2 \leq p \lt 2^{31}$。
# 解决
## 暴力循环
## 倍增+二进制
1. 为解决超时问题 , ==将b以二进制数表示==
	例如 $a^{11}= a^{(1011)_2} = a^{(2^3\times1+2^2\times0+2^1\times1+2^0\times1)} =   a^{2^3\times1}\times a^{2^2\times0}\times a^{2^1\times1}\times a^{2^0\times1} = a^8 \times 1\times a^2\times a^1$
	此时将b二进制的每个数位看做a的阶数
	就只需要遍历b的二进制数位,此时 时间复杂度 = $O(\log b)$
	即b的 二进制数位
2. 为解决存储问题 , 根据取模运算的规则化简运算
	+ 取模运算的规则 : 
		+ 当计算过程中,只有 "加法运算" 和  "乘法运算" 时
			==取模运算可以 放到任意位置,进行任意次取模运算==
		+ 当计算过程中存在 "减法运算" 时,结果可能是负数,此时如果需要补正
			就需要进行"==模加模=="的技巧
			+ 例如$(a-b) \% p$ 为负数 , 通过"模加模"得到 : $((a-b)\%p+p)\%p$
		+ 当计算过程中存在"除法运算"时,取模会造成结果错误
			此时就需要==求逆元==
