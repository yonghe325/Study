[P10449 费解的开关 - 洛谷](https://www.luogu.com.cn/problem/P10449)
# 性质
+ 每一盏灯,最多只会点一次
	对于一盏灯而言,只有按或不按两种状态
	+ 即一盏灯状态切换为偶数次时 : 相当于没变
		为奇数次时,才会变化
	+ 所以对暗的灯来说,必须切换奇数次
		对亮的灯来说,必须不切换,或者切换偶数次
+ 按法的先后顺序,是不影响最后结果的
	不用关系按的顺序,只用关心最后结果
	只用计算灯状态的初始状态,和切换次数
+ 第一行的灯按法确定后,后续灯的按法就会跟着确定
# 思路 
1. 暴力枚举第一行的所有按法
2. 根据第一行的按法,计算当前行以及下一行的被按后的结果
3. 根据第一行的结果,推导出第二行的结果,重复2,3过程
4. 重复2,3步
# 解法
+ 使用二进制存放第一行的按法
	从0到(0<<5)-1
	使用1代表需要按,0代表不按
+ 统计每个灯一共被按了多少次
	统计二进制中一共有多少个1
	使用lowbit,统计二进制表示中有多少个1
	将1累加
+ 统计每一行灯的状态
	用一个数,存放每一行的状态
	存的时候把0存放为1,把1存放为0
	此时结束条件从全亮变为全灭
	最后判断存放每一行的状态数是否为00000 = 0
+ 统计每一行灯被按后的状态
	直接将每一行灯的原始状态 异或 每一行灯的按法
	例如 : 
	+ $a_i = 10111$  $push_i = 00100$
	+  即$a_i \wedge push_i\wedge (push_i<<1)\wedge(push_i>>1) = b_i$
		异或push中1的左右两位
	+ 第二行直接异或上一行的push,不让其修改push中1的左右两位
		$a_{i+1}\wedge push_i$
		然后递归,直到最后一行
+ 第i+1行被按的按法
	第i+1行的按法以上一行的结果相同
	$push_{i+1} = b_i$
