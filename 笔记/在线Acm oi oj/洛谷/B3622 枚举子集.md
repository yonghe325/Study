[B3622 枚举子集（递归实现指数型枚举） - 洛谷](https://www.luogu.com.cn/problem/B3622)
## 题目描述
今有 $n$ 位同学，可以从中选出任意名同学参加合唱。
请输出所有可能的选择方案。
## 输入格式
仅一行，一个正整数 $n$。
## 输出格式
若干行，每行表示一个选择方案。
每一种选择方案用一个字符串表示，其中第 $i$ 位为 `Y` 则表示第 $i$ 名同学参加合唱；为 `N` 则表示不参加。
==需要以字典序输出答案== (二进制枚举不再适用)
## 输入输出样例 #1
### 输入 #1
```
3
```
### 输出 #1
```
NNN
NNY
NYN
NYY
YNN
YNY
YYN
YYY
```
## 说明/提示
对于 $100\%$ 的数据，保证 $1\leq n\leq 10$
# 解决 
## 递归DFS
在字典序中,N>Y
所以N总是优先出现在Y的前面
根据题意,每个人的状态只有Y和N两种
==对应的决策树就是二叉树==
即每层代表对应的次序的人的状态
且N总是出现在右子树
![[Pasted image 20251230115735.png]]
==利用全局变量和回溯==
```c++
#include<iostream>
#include<string.h>
using namespace std;
int num;
string path = "";
void dfs(int pos) {
	if (pos > num) {
		cout << path << endl;
		return;
	} 
	path += "N";
	dfs(pos + 1);
	//for (int i = num-pos; i >= 0; i--) path.pop_back();
	//回溯
	//回溯到pos的上一层
	path.pop_back();

	path += "Y";
	dfs(pos + 1);
	path.pop_back();
}

int main() {
	cin >> num;
	dfs(1);
	return 0;
}
```
