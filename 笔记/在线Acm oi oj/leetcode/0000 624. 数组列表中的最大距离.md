+ ans
	记录当前的最大值
+ a
	为当前遍历到的数组
+ mn,mx
	为记录中的最小值,和最大值
+ 为什么先进行`ans = max({ans, a.back() - mn, mx - a[0]})`
	先更新ans, 此时mn,mx还没有涉及到当前a中的元素
	保障mn,mx不会出现在同一个数组
	+ 如果先更新 mn 和 mx
		可能会发生mn,mx出现在同一个数组中的情况
```cpp
class Solution {
public:
    int maxDistance(vector<vector<int>>& arrays) {
        int ans = 0;
        int mn = INT_MAX / 2, mx = INT_MIN / 2; // 防止减法溢出
        //如果mx = INT_MIN, mx - a[0]可能会溢出
        for (auto& a : arrays) {
            ans = max({ans, a.back() - mn, mx - a[0]});
            //在ans, a.back() - mn, mx - a[0]三者中取最大值
            mn = min(mn, a[0]);
            mx = max(mx, a.back());
        }
        return ans;
    }
};
```
