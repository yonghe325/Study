2. ==如果窗口中有 c 个相同元素 x，再去掉一个 x，会减少 c−1 个相等数对==

这是在涉及阶乘时的替代方法
将计算阶乘, 转换为统计当前个数
## 刚好满足条件时, 计算后面的个数
```cpp
class Solution {
public:
    long long countGood(vector<int>& nums, int k) {
        int ret = 0;
        map<int, int> arr;
        int count = 0;
        int left = 0;
        for(int i =0; i<nums.size();i++){
            count+=arr[nums[i]];
            arr[nums[i]]++;
  
            while(count >= k){
	            ret += nums.size()-i;
            //当count >= k成立时, 说明当前窗口刚好满足条件
            //所以以left结尾, 到最后的所有子串也必然满足条件
            //nums.size()-i就是这些子串的个数
                arr[nums[left]]--;
                count -= arr[nums[left]];
                left++;
            //去除left位置的数对当前对数的贡献
            }
        }
        return ret;
    }
};
```
