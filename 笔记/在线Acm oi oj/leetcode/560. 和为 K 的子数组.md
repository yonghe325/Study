# 哈希表 + 前缀和
## `hash[0]++;`的作用
如果一个前缀和恰好为k
则说明从下标0到当前下标的子数组满足条件
此时一开始的`hash[0]++`就派上用场
使当前数组可以被统计, 并将`hash[0]++`
此时该元素变成一个结点
之后如果还有恰好为k的前缀和
该结点表示可以从目标位置到该结点可以组成一个满足条件的子数组
## 代码:
```cpp
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        map<int,int>hash;
        //存储所有前缀和出现的次数
        int sum = 0;
        hash[0]++;
        int ret = 0;
        for(int i =0; i<nums.size();i++){
            sum+=nums[i];
            // if(sum>=k){
            ret+=hash[sum-k];
                //如果没有就是0个(可能有负数, 所不能通过sum>=k进行过滤)
                //如果有,就加上当前的个数
            // }
            //如果当前位置的前缀和>=k
            //查找map中sum-k前缀和出现的次数
            hash[sum]++;

        }

        return ret;

    }

};
```
