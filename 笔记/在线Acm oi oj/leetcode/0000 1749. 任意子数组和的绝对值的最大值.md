即 最大的前缀和 - 最小的前缀和
最大的前缀和 与 最小的前缀和 的位置无关答案
因为求得是==绝对值==
绝对值的大小与位置无关
```cpp
class Solution {
public:
    int maxAbsoluteSum(vector<int>& nums) {
        int s = 0, mx = 0, mn = 0;
        for (int x : nums) {
            s += x;
            mx = max(mx, s);
            mn = min(mn, s);
        }
        return mx - mn;
    }
};
```
