最大子数组和相当于原数组两个前缀和的差
所以只需要找到差最大的两个前缀和
遍历求前缀和, 再求前缀和的过程中, 记录最小前缀和
若当前前缀和大于记录的最小前缀和
则比较当前的差值
返回最大的差值
+ 先更新ans
	防止一个前缀和自减
	在更新最小值
```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int ans = INT_MIN;
        int min_pre_sum = 0;
        int pre_sum = 0;
        for (int x : nums) {
            pre_sum += x; // 当前的前缀和
            ans = max(ans, pre_sum - min_pre_sum); // 减去前缀和的最小值
            min_pre_sum = min(min_pre_sum, pre_sum); // 维护前缀和的最小值
        }
        return ans;
    }
};
```
