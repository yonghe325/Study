+ L 的范围
	对于整个数组来说
	所有数都必须至少操作一次
	所以`nonPositive(nums,k)>=nums.size()`
	又因为要求`nonPositive(nums, k) <= k^2`
	所以`k^2>=nums.size()`
	令`n = nums.size()`
	即`k>=ceil(sqrt(n))`
	所以当`k<ceil(sqrt(n))`时, 该k一定不成立
	所以令`k`的下界 = `ceil(sqrt(n)) - 1`, ==保证下界一定不成立==
	+ 下界如果设置为0的话，nums =[1,1] 这种数据无法通过
		所以下界是不是没有办法直接用0 这种不满足条件来进行处理
		只能根据数组的长度动态调整下界
+ R 的范围
	`nums`排序之后, 当`k = nums[n-1]`时,`nonPositive(nums, k)`取得最小值`n`
	即每个元素只操作一次
	+ 如果`n<==nums[n-1]^nums[n-1]`, 即`k = R`时, 上界满足要求
	+ 特殊情况`nums[n-1]<=ceil(sqrt(n))`时,此时上界小于`k`的理论值小于`ceil(sqrt(n))`
		满足`nonPositive(nums, k) <= k^2`的最小值就是`nums[n-1]`
		直接返回`ceil(sqrt(n))`
```cpp
class Solution {
public:
    int minimumK(vector<int>& nums) {
        int n = nums.size();
  
        auto check = [&](int k) -> bool {
            long long sum = n;
            for (int x : nums) {
                sum += (x - 1) / k;
            }
            return sum <= 1LL * k * k;
            //sum = nonPositive(nums, k)
            //若sum <= k ^ 2
            //则k还可以变小, 继续查找更小的满足条件的k
            //若sum > k ^ 2
            //则此时 nonPositive(nums, k)在下界
            //让k变大
        };
  
        int left = ceil(sqrt(n)) - 1;
        int right = ranges::max(nums);
        while (left + 1 < right) {
            int mid = (left + right) / 2;
            (check(mid) ? right : left) = mid;
        }
        return left + 1;
    }
};
```
