# 哈希表 + 前缀和
## 灵神
把负数前缀和调整为==非负数==。
如果不调整负数，会出现同余的数据没有汇总的情况
例如 k=4，−1 和 3 关于模 k 同余，如果不调整 −1，那么哈希表会分开保存 −1 和 3
如果当前前缀和为3, 就需要1或-3前缀和
//1的余数为1
//说明-3等价于1
就可以把负数前缀和转化成非负数
正确做法是==把 −1 的个数汇总到 3 ==上
```cpp
class Solution {
public:
    int subarraysDivByK(vector<int>& nums, int k) {
        unordered_map<int, int> cnt;
        int ans = 0, s = 0;
        for (int x : nums) {
            cnt[s]++;
            s = (s + x % k + k) % k; // 保证 s 非负
            ans += cnt[s];
        }
        return ans;
    }
};
```
## self
+ 如果当前余数前缀和为正数
	就找正数同余数或负数补数
+ 如果当前余数前缀和为负数
	就找负数同余或正数补数
```cpp
class Solution {
public:
    int subarraysDivByK(vector<int>& nums, int k) {
        map<int,int>hash;
        long long sum =0 ;
        int ret  = 0;
        for(int i =0; i<nums.size();i++){
            sum += nums[i];
            // ret +=sum%k?0:1;
            //能被k整除, ret++
            ret+=(sum%k?0:1) + hash[+sum%k];
            //如果当前sum能被k整除
	            //ret就++, 
            //寻找hash中出现的同余数
	            //先把sum变成正数
	            //如果sum是正数, hash[+sum%k]代表加上hash中的同余数
	            //如果sum是负数, 相当于加上正数补数
            //判断sum是否为正负数
            if(sum>=0)
			//如果为正数
			//寻找负数补数
                ret+=hash[-(k-sum%k)];
                //寻找 +sum%k 或 -(k-sum%k);
            else
            //如果sum为负数
            //在hash中寻找负数同余数
                ret+=hash[k+sum%k];
                //寻找 + (sum%k)  或 k + (sum%k)
            hash[sum%k]++;
            // cout<<i<<" "<<sum%k<<" "<<hash[sum%k]<<endl;
        }  
        return ret;
    }
};
//存储每个元素%5的余数
//当计算到新的前缀和时, 寻找满足余数的元素
```
