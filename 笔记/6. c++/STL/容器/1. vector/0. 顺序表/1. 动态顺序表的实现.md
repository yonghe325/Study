# vector
使用new和delete来申请和释放空间时
效率太低,还可能造成内存泄露
此时就可以使用vector来实现动态顺序表
# 动态申请
使用new和delete来申请和释放空间
```c++
//第一次开辟空间
	int* a;
	a = new int[4];
	capacity = 4;
//空间不够,扩容
	int* tmp = new int[capacity*2];
	//拷贝
	memcopy(t,a,sizrof(int)*capacity);
	//释放原来数组
	delete[] a;
	a = t;
	capacity*=2;
//空间不够,扩容
```
## new
在内存中申请连续的区域
返回地址
## delete
释放new开辟的空间
