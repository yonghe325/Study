==在c++11里引入==
基于范围的for循环
可以不用得知数组的长度
将所有数组中所有数据全部遍历
# 传值for
```c++
for(类型 临时变量名 : 数组名){
	语句...
}
```
会把数组里的元素依次放到临时变量里去
临时变量的值与本次循环中数组中对应的值相同
==临时变量的类型必须与数组的类型相同==
==不能通过临时变量改变数组里的内容==
## auto自动识别类型]
[[1. auto关键字]]
```c++
for(auto 临时变量名 : 数组名){
	语句...
}
```
此时临时变量会自动识别数组的类型,并自动赋值
# 传址for
```c++
for(类型 &临时变量名 : 数组名){
	语句...
}
```
通过解引用直接改变数组中的值
