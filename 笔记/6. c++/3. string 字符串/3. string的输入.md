# getline
读取一行文本 , 存储为字符串
可以读取空格
getline有两种形式
```c
getline(istream& is,string& str);
getline(istream& is,string& str,char delim);
//istream : 输入流类型 : 标准输出流 , 文件输出
//ostream : 输出流类型
```
## getline(istream& is,string& str);
一换行符'\n'为结束标志
即从输入流中一直读取字符,直到读到'\n'为止
并将读取的文本,存储到string类型变量里去
==存储的文本不包含'\n'==
## getline(istream& is,string& str,char delim);
以delim作为结束标志
使得用户可以自定义结束标志
==存储的文本不包含delim==
