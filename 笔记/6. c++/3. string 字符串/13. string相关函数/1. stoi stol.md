```c++
int stoi(const string& str,size_t*idx = 0,int base = 10);
long stol(const string& str,size_t*idx = 0,int base = 10);
```
`stoi`将字符串转化为`int`类型的值
`stol`将字符串转化为`long int`类型的值
舍弃所有空白符,直到找到首个不为空白符的字符
+ 形参 : 
	+ `str` : 被转化字符串
	+ `idx` : 返回`str`中==无法正确匹配数字的第一个字符的位置(下标)== 
		`idx`是一个==输出型参数==,通过这个参数会带回一个值
		`idx`是一个指针
			需要在外面创建一个`size_t`类型的变量
			将这个变量的地址作为`idx`
	+ `base` : 表示被解析的字符串中数字的==进制值==,==最终会被返回为十进制==
		默认为10,即十进制
		+ 当`dase`前有`+-`时 , 会转化为正/负
		+ 当`base`为2时 , 表示==被解析的字符串中的数字为二进制数字==
		+ 当`base`为8时 , 表示被解析的字符串中的数字为八进制数字
		+ 当`base`为16时 , 表示被解析的字符串中的数字为十六进制数字
		+ 当`base`为0时 , 会根据字符串的内容的信息自动推导进制
			如字符串数字前有0X,则表示为十六进制
			有0,则表示为八进制
		+ 当$2 \leq base\leq36$时,表示对应的进制
+ 返回值 : 被转化字符串对应的数的值
+ 异常 : 
	+ 当首个非空字符不为数字时,抛出异常
	+ 若转化后的结果不为对应的返回值,抛出异常
## 案例
```c++
	string s1 = "123qw";
	string s2 = "qw123";
	//未定义行为 : 非数字字符开头
	size_t tag1;
	size_t tag2;
	int ret1 = stoi(s1, &tag1, 10);
	//int ret2 = stoi(s2, &tag2, 10);
	cout << "ret1 = " << ret1 << endl << "tag1 = " << tag1 << endl;
	//cout << "ret2 = " << ret2 << endl << "tag2 = " << tag2 << endl;
```
