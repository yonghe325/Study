find()函数用于查找字符串中指定子串/字符
并返回==子串/字符==在字符串一次出现的位置
```c++
size_t find(const string& str, size_t pos = 0) const;
//查找string类型的字符串str,默认是从头开始,pos可以指定下标位置开始
//pos参数不写,则默认为0

size_t find(const char* s, size_t pos = 0) const;
//查找c风格的字符串,默认是从头开始,pos可以指定下标位置开始

size_t find(const char* s,size_t pos, size_t n) const;
//在字符串的pos这个位置 开始查找 c风格字符串s 中的 前n个字符

size_t find(char c, size_t pos = 0) const;
//查找字符c,默认是从头开始,pos可以指定下标位置开始
```
+ 返回值
	+ 若找到,返回字符串中第一次出现的起始下标的位置
	+ 若没找到,返回一个整数值`npos`
# npos
```c++
static const size_t npos = -1;
cout << string::npos<<endl;
```
npos为c++中string库 里定义的一个==静态常量==
由于npos为size_t类型(无符号整形)
导致npos其实是一个非常大的数
(18446744073709551615)
当用于比较时,应说明npos为string里的常量
```c++
string s = "aaaaaaa";
size_t n = s.find('b');
if(n == string::npos){
	cout << "没找到 'b' " << endl;
}  
```
