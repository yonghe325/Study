迭代器时一种对象,可以用来遍历容器中的元素
迭代器的作用类似于指针和数组下标
范文迭代器指向的值,需要解引用(  \*  )
# 创建迭代器
```c
string s = "abcdef";
string::iterator it1 = s.brgin();
string::iterator it2 = s.end();
```
+ 迭代器可以运算,比较
	两个迭代器相减,返回两个迭代器之间元素的个数
```c
if(it1 < it2){
	cout << "<" << endl;
}
else{
	cout << ">" << endl;
}
```
+ 传值遍历
```c
for(string::iterator its = s.begin();its!=s.end();its++){
	cout <<*its <<" "<<endl;
}
//正序遍历
//或
for(string::iterator ite = s.end();ite!=s.begin();ite--){
	cout <<*ite <<" "<<endl;
}
//倒序遍历
//或
for(auto it = s.begin();it!=s.end();it++){
	cout <<*it <<" "<<endl;
}
```
+ 传址遍历
```c
for(string::iterator its = s.begin();its!=s.end();its++){
	*its = 'a';
}
```
# begin() 和 end()
begin() : 返回指向==字符串第一个字符的迭代器== , 需要一个迭代器的变量来接收
end() : 返回指向字符串==最后一个字符的下一个位置==的迭代器 ( 该位置不属于字符串 ) 
string中begin()和end()返回的迭代器的类型是==string::iterator==
