substr函数用于截取字符串中指定位置指定长度的子串
```c++
string substr (size_t pos = 0, size_t len = npos ) const;
//pos 的默认值是0
//len 的默认值是npos,意思是截取到字符串的末尾
```
+ 传参 : 
	+ substr()
		截取整个字符串
	+ substr( pos )
		从下标pos的位置截取子串,直到结尾
	+ substr( pos , len)
		从下标pos的位置截取长度为len的子串
		当剩余长度不足len时 , 只会截取剩余的长度
+ 返回值 : 
	+ 返回截取的字符串
		不是返回原有字符串中的字符的地址
		而是重新创建一个字符串为截取的字符串
+ 使用 :
	+ substr + find : 
		find查找子串位置
		substr向后截取子串
