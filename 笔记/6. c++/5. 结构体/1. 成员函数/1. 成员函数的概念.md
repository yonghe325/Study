**结构体内的函数就叫成员函数**
C++的结构体会有⼀些默认的成员函数
比如构造函数,解析函数等
成员函数可以直接访问成员变量
成员函数的调⽤也使⽤ **.** 操作符
```c++
struct{
	结构体成员变量列表;
	结构体成员函数;
	//成员函数可以有,也可以没有
}结构体变量列表;

//代码1-演⽰⾃定义成员函数 
#include <iostream>
using namespace std;
struct Stu
{
	 //成员变量 
	 string name;
	 int chinese;
	 int math;
	 int total;
 
	 void init_stu() //初始化 
	 {
		 name = "⼩明";
		 chinese = 99;
		 math = 95;
		 total = math + chinese;
	 } 
 
	 void print_stu() //打印 
	 {
		 cout << "名字:" << name << endl;
		 cout << "语⽂:" << chinese << endl;
		 cout << "数学:" << math << endl;
		 cout << "总分:" << total << endl;
		 //可以直接访问结构体内变量
	 }
};
int main()
{
	 struct Stu s;
	 s.init_stu();
	 //调用
	 s.print_stu();
	 return 0;
}
```
