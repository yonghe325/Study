# void* 泛型指针类型
```
int a =10;

int* pa = &a;
char* pc = &a;//不兼容
void* pv = &a;
```
void* 指针表示 ***==无具体类型的指针==***
这种指针 ==可以接受任意类型的地址==
由于可以接受任意类型的地址
所以:
+ 无法 直接解引用
+ 无法 +-整数的操作(运算)
## 使用方法
先将 void* 类型指针 强制类型转换为 其他类型指针
然后 解引用

# 负数赋值指针
```
int* p =-4;
-4的原反补码:
10000000 00000000 00000000 00000100
11111111 11111111 11111111 11111011
11111111 11111111 11111111 11111100
```
由于变量在内存中以补码的形式存在
所以
```
int* p = 0b 11111111 11111111 11111111 11111100
即
int* p = 0X FF FF FF FC
```
# %p打印内存中的补码
==当使用%p格式输出一个**负数/有符号数**时
会直接将该数的补码直接打印==
