## sport 快速排序
使用 ==快速排序的思想== 的一个排序函数
该函数可以排序==任意类型==的数据
<stdio.h> and <search.h>
![[qsort.png]]
```
 void qsort( void *ptr, 
		//你要排序的数据的起始位置
			 size_t count,
		//待排序的数据元素的个数
			 size_t size,
		//待排序的数据元素的大小
			 int (*cmp)(const void* e1, const void* e2) ); 
		//函数指针-比较函数
```
###  int (\*cmp)(const void* e1, const void* e2) 解释
+ cmp
 cmp指向 ==自定义比较函数== 的地址
 ==排序不同数据类型的方式不同==:整形,字符型,结构体...
 所以将排序方式提取
 通过 ==提供的排序方式== 进行排序
+ void\* 类型指针
 转到[[8. 特殊指针运用#void* 指针]]
 由于无法直接确认比较的元素类型
 选择用void* 类型指针接收
+ void* e1
 指向 比较的第一个元素 的地址
+ void* e2
 指向 比较的第二个元素 的地址
+ 解引用e1,e2
将e1,e2强制类型转换为 比较类型对应的指针变量
然后解引用
+ 规定 特殊返回值
 若e1 < e2 , 返回 <0 的一个整形 , 两数交换位置
 若e1 = e2, 返回0 , 位置不变
 若e1 > e2, 返回 >0 的一个整形 , 位置不变

### 用法
```
int compare_ints(const void* a, const void* b)
{
    int arg1 = *(const int*)a;
    int arg2 = *(const int*)b;
//将void* a,void* b 强制类型转换为 int* 类型
//然后解引用
    if (arg1 < arg2) return -1;
    if (arg1 > arg2) return 1;
    return 0;
 
    // return (arg1 > arg2) - (arg1 < arg2); // 可行的简写
    // return arg1 - arg2; // 错误的简写（若给出 INT_MIN 则会失败）
}

int main()
{
    int ints[] = { -2, 99, 0, -743, 2, INT_MIN, 4 };
    int size = sizeof ints / sizeof *ints;
 
    qsort(ints, size, sizeof(int), compare_ints);
 
    for (int i = 0; i < size; i++) {
        printf("%d ", ints[i]);
    }
    
    return 0;
}
```
