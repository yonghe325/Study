# 中序线索二叉树
## 找中序前驱

1. ltag = 1
	表明左指针为前驱,直接查找
2. ltag = 0
	其前驱为左子树中,第一个没有右分支的结点
	即该结点==左子树最右下的结点==
	表明左指针指向左分支
	+ 在中序线索二叉树中
		总是按照LDR的顺序进行顺序化
		表明对一个度大于1的结点来说
		他的前驱总是它的左子树中
		离它最近的无右分支的结点
## 找中序后继
1. rtag = 1
	右指针指向后继
2. rtag = 0
	右指针指向右分支
	其后继为右子树中,第一个没有左分支的结点
	即该结点==右子树最左下的结点==
	原理同找前驱相同

# 先序线索二叉树
## 找前驱
1. ltag =1
2. ltag =0
	对于DLR线索二叉树来说
	总是按照根->左->右的顺序查找
	所以一个结点的前驱有如下情况:
	+ 如果是整棵树的根节点,则没有前驱
	+ 如果是父节点的左分支,其前驱是自己的父结点
	+ 如果是父节点的右分支,有如下两种情况:
		+ 父节点的左分支为NULL,则其前驱为父结点
		+ 父节点的左分支不为NULL
			则为父结点的左分支中
			最后遍历的结点
	上述情况都需要寻找父结点,可以为结点添加父指针,或者从头遍历
## 找后继
1. rtag = 1
2. rtag =0
	表明右指针指向右分支
	+ 如果有左分支,则其后继为左结点
	+ 如果没有左分支,则其后继为它的==右结点==

# 后序线索二叉树
## 找前驱
1. ltag = 1
2. ltag = 0
	对于后序线索二叉树来说
	+ 其前驱为从右向左第一个不为NULL的结点
		有右子树, 其前驱为其右结点
		没有右子树, 其前驱为其左结点
## 找后继
1. rtag = 1
2. rtag = 0
	有如下情况 :
	+ 结点为整棵树的根节点,则无后继
	+ 如果为其父结点的右结点,则其父结点为它的后继
	+ 如果为其父结点的左结点
		其后继为它 父结点==以及==父结点的右子树中 的第一个结点
	都需要父指针
