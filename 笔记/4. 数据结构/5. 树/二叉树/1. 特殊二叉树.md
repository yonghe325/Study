# 满二叉树
+ 所有分支结点都有两个度
+ 所有叶结点都在最后一层
# 完全二叉树
==完全二叉树可以使用数组作为存储结构==
+ 除最后一层外,所有层结点都为满
+ 最后一层必须从左到右连续排列
	即最后一层不能有单独的右叶结点
## 性质
从上到下,从左到右依次编号1,2,...,n
![[Pasted image 20251203183809.png]]
1. 对于i号结点 : 
	+ ==左分支 : 2i==
	+ ==右分支 : 2i + 1 ==
	+ ==父节点 ==: $\lfloor\frac{i}{2}\rfloor$
2. 最后一格分支结点的编号为$\lfloor\frac{n}{2}\rfloor$n为总结点个数
	+ $\lfloor\frac{n}{2}\rfloor$后的结点都为叶结点
3. 最多只可能有一个 度为1 的结点
	+ n为奇数时,没有 度为1 的结点
	+ n为偶数时,有一个 度为1 的结点
		该节点编号为$\lfloor\frac{n}{2}\rfloor$
		且只有左分支,没有右分支
4. 叶结点只可能在最后两层
5. 具有n个结点的完全二叉树的高度为$\lceil\log_2{(n+1)}\rceil$
+ 解释 : 
 1. 当n最少的时候,有$n_{min} = 2^{h-1}-1+1 =2^{h-1}$
[[Pasted image 20251203184938.png]]
 2. 当n最多的时候,有$n_{max} = 2^{h}-1$ 
 3. 所以有
	$$\begin{flalign}
	&2^{h-1}\leq n \leq2^{h}-1\\\\
	&\text{等价为}\\\\
	&2^{h-1}-1< n \leq2^{h}-1(1)\\\\
	&\text{或}\\\\
	&2^{h-1}\leq n <2^{h}(2)\\\\
	&\text{对(1)两侧同时+1,取以2为底的对数}\\\\
	&2^{h-1}-1< n \leq2^{h}-1(1)\\\\
	&=2^{h-1}< n+1 \leq2^{h}\\\\
	&=h-1<\log_2{(n+1)}\leq h\\\\
	&\text{等价于}\\\\
	&\log_2{(n+1)}\leq h <\log_2{(n+1)}+1\\\\
	&\text{因为h必须是整数}\\\\
	&\text{所以有}\\
	&h_{max} = \lceil\log_2{(n+1)}\rceil;
	\end{flalign}$$
