二叉树的遍历有两种方式
DFS 和 BFS
先序,中序,后序都是DFS
层序是BFS
# DFS 递归序
二叉树递归有如下经典结构
在递归中,无论那一层
都会回到该结构 ==三次====
即每个结点都会被查找三次==
```c
void Fn(Node* head){
//第一次 : 进入
	if(head == NULL){
		return;
	}
	Fn(head->left);
//第二次 :返回 
//左分支递归完返回
	Fn(head->right);
//第三次 :返回 
//右分支递归完返回

//第三次返回后,后续无语句
//结束本层循环
}
```
==按照该顺序查找的结点的顺序==
==被称为二叉树的递归序==
最先结束递归的是最左侧的子树/结点
最后结束递归的是最右侧的子树/结点
## 衍生递归序
根据第几次返回到该节点
==由此衍生出二叉树的三种递归顺序==
===先序,中序,后序===
同一棵树,相同的遍历顺序一定是相同的
### 先序遍历DLR : 根->左->右

### 中序遍历LDR :左->根->右
![[Pasted image 20251204130235.png]]
=先递归访问左分支=,在访问根结点,在访问右分支 
### 后序遍历LRD : 左->右->根
![[Pasted image 20251204130529.png]]
先访问左分支,在访问右分支,最后访问根结点

```
typedef struct TreeNode
{
    int data;
    TreeNode * left;
    TreeNode * right;
    TreeNode * parent;
}TreeNode;
 
void pre_order(TreeNode * Node)//前序遍历递归算法
{
    if(Node == NULL)
        return;
    printf("%d ", Node->data);//显示节点数据，可以更改为其他操作。在前面
    pre_order(Node->left);
    pre_order(Node->right);
}

void middle_order(TreeNode *Node)//中序遍历递归算法
{
    if(Node == NULL)
        return;
    middle_order(Node->left);
    printf("%d ", Node->data);//在中间
    middle_order(Node->right);
}

void post_order(TreeNode *Node)//后序遍历递归算法
{
    if(Node == NULL)
        return; 
    post_order(Node->left);
    post_order(Node->right);
    printf("%d ", Node->data);//在最后
}
```
