# 哑节点法
## 哑节点的定义
哑节点又称虚拟节点
哑节点是一个额外添加在链表头部的节点
这个节点**通常不存放实际要处理的数据**
主要是为了简化 链表操作 的代码逻辑
***尤其是在对链表头部进行插入、删除等操作时能带来很多便利***
### 优点
+ 插入
在单向链表中插入新节点时，正常情况下如果在表头插入，需要特殊处理表头指针的更新
有了哑节点后，插入操作可以统一
因为哑节点始终指向原来的第一个节点
当插入新节点时，新节点的next指针指向哑节点原来指向的节点，然后哑节点再指向新插入的节点
这样无论在链表的任何位置插入节点，都可以使用类似的逻辑，使得插入操作代码更加简洁和统一
+ 删除
对于删除操作，在没有哑节点时，删除头节点需要单独处理表头指针的更新和内存释放
而有哑节点时，要删除的节点（包括头节点）前面都有一个前驱节点
（对于头节点来说，哑节点就是前驱节点）
通过前驱节点来调整指针关系，就可以统一删除操作的逻辑
例如，要删除哑节点后的第一个节点（即原来的头节点）
可以先将哑节点的next指针指向要删除节点的下一个节点，然后释放要删除的节点内存
+ 遍历
当遍历链表时，使用哑节点可以简化边界情况处理
正常情况下，需要先判断链表是否为空（即表头指针是否为NULL）来决定是否开始遍历
有了哑节点后，无论链表是否为空，都可以从哑节点的下一个节点开始遍历
因为如果链表为空，哑节点的next指针为NULL
如果链表不为空，哑节点的下一个节点就是真正的第一个有效节点。


##  解法
```
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
struct ListNode* removeNthFromEnd(struct ListNode* head, int n) {
    struct ListNode*dummy = malloc(sizeof(struct ListNode));
    dummy->val = 0;
    dummy->next = head;
    //dummy->next始终指向头结点
    int count = 0;
    struct ListNode* Count = head;
    while(Count){
        count++;
        Count = Count->next;
    }
    //计算节点个数,得到节点个数count
    Count = dummy;
    for(int i =1;i<count-n+1;i++ ){
        Count = Count->next;
        //得到倒数第那n个节点的前置节点
    }
    Count->next = Count->next->next;
    Count = dummy->next;
    //删除倒数第n个节点
    free(dummy);
    return Count;
}
```
