# 一维差分数组 :
+ 作用 : 快速解决" 将某一个区间的所有元素统一加上一个数 "的操作
+ 时间复杂度 : O(1)
+ 差分数组的性质:
	+ 在原数组的$[L,R]$区间全部加这个操作
		相当于在差分数组中,$f[L]+=k,f[R+1]-=k$
+ 实现方式 : 
	1. 创建数组f,存储原数组a  中 ==当前元素与前一个元素的差值==
		即$f[i] =a[i]-a[i-1]$
+ ==注意==:
	+ 在使用差分数组时 
		所有在差分数组上修改的操作必须全部完毕,才能还原操作之后的数组
		即修改和查询不能同时进行
		此时就可以使用==线段数==算法
## 差分数组创建方式
### 使用原数组+差分数组
```c++
const int N = 1e5 + 10;
int arr[N] = { 0 };
int f[N] = { 0 };

cin >> n;
//n为数组元素个数
for (size_t i = 1; i <= n; i++){
	cin >> arr[i];
	//获取原数组
	f[i] = arr[i] - arr[i - 1];
	//计算差分数组
} 

for (int i = 1; i <= n; i++)
{
	arr[i] = arr[i - 1] + f[i];
}
//统计前缀和
```
### 利用差分性质直接创建差分数组
在$arr[i]$处填入一个元素k
相当于在$f[i]+=k$,在$f[i+1]-=k$
利用此性质,可以直接创建差分数组
```c++
const int N = 1e5 + 10;
int f[N] = { 0 };
long long x;
for (int i = 1; i <= n; i++){
	cin >> x;
	f[i]+=x;
	f[i+1]-=x;	
}

for (int i = 1; i <= n; i++)
{
	f[i] = f[i - 1] + f[i];
}
//统计前缀和

```
