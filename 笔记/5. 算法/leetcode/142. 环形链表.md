# 快慢指针法
[环形链表](https://leetcode.cn/problems/linked-list-cycle-ii/solutions/441131/huan-xing-lian-biao-ii-by-leetcode-solution/)

```C
struct ListNode *detectCycle(struct ListNode *head) {
    if(!head || !head->next || !head->next->next  ){
        return NULL;
    }
    struct ListNode *slow = head->next;
    struct ListNode *fast = head->next->next;
    while(slow != fast){
        if(!fast->next || !fast->next->next){
            return NULL;
        }
        slow=slow->next;
        fast = fast->next->next;
    }
    //两指针相遇
    fast = head;
    while(fast != slow){
        fast = fast->next;
        slow=slow->next;
    }
    return fast;
}
```
