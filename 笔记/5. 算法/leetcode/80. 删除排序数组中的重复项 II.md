# 快慢指针法
+ 因为给定数组是有序的，所以相同元素必然连续。我们可以使用双指针解决本题，遍历数组检查每一个元素是否应该被保留，如果应该被保留，就将其移动到指定位置
+ 具体地，我们定义两个指针 slow 和 fast 分别为慢指针和快指针
其中慢指针表示处理出的数组的长度，快指针表示已经检查过的数组的长度
即 nums[fast] 表示待检查的第一个元素
nums[slow−1] 为上一个应该被保留的元素所移动到的指定位置。

+ 因为本题要求相同元素最多出现两次而非一次
+ 所以我们需要检查上上个应该被保留的元素 nums[slow−2] 是否和当前待检查元素 nums[fast] 相同
+ 当且仅当 nums[slow−2]=nums[fast] 时
当前待检查元素 nums[fast] 不应该被保留
（因为此时必然有 nums[slow−2]=nums[slow−1]=nums[fast]）
最后，slow 即为处理好的数组的长度。

+ 特别地，数组的前两个数必然可以被保留，因此对于长度不超过 2 的数组，我们无需进行任何处理，对于长度超过 2 的数组，我们直接将双指针的初始值设为 2 即可。
```c
int removeDuplicates(int* nums, int numsSize) {
    if (numsSize <= 2) {
        return numsSize;
    }
    int slow = 2, fast = 2;
    while (fast < numsSize) {
        if (nums[slow - 2] != nums[fast]) {
            nums[slow] = nums[fast];
            ++slow;
        }
        ++fast;
    }
    return slow;
}
```
只需要比较nums[fast]和nums[slow - 2]
因为：nums[slow - 1]表示最新的被更新的元素
一定有 nums[slow - 2] <= nums[slow - 1] <= nums[fast]
	这个数组本身是单调不减的，[0, slow - 1]的新结果也是单调不减的
	而nums[fast]也肯定大于等于它之前遍历过的下标[0, slow - 1]范围的元素
+ 如果nums[slow - 2] == nums[slow - 1]，则nums[fast] == nums[slow - 2]就说明已经有2个重复元素了，fast指针处的元素要丢弃
+ 如果nums[slow - 2] < nums[slow - 1]，则nums[fast] != nums[slow - 2]恒成立
此时nums[fast]一定会被保留
说明nums[slow - 1]这个元素还只有一个，可以更新nums[slow] = nums[fast]
## 推广至保留k个数
+ 必定保留前k个数
	+ 前k个数作为缓冲
		+  ==前k个数 必然相等 或 单调增==
+ 从第k+1个数开始,通过[fast]与[slow]与[slow-k]比较
	+ 最初[fast] 与 [slow]下标相同
	+ 若[fast] == [slow-k]
		+ 则说明[fast]与第[slow-k]个数之间必然相等
			应舍去第[slow]个数
			使得连续的相同的数的个数为k
		+ 所以[slow]不变,[fast]向后查找
			直到找到与[slow]不同的数,将[slow]更新,并将[slow]下标向后更新
		+ 此时,[slow-k]与[fast]之间必然不连续
			且 [slow-k]与[fast]之间 与 [fast]之后的数必然不相等
		+ 所以[slow]与[fast]将同时向后更新
			直到[slow-k]遍历到
	+ 若[fast] != [slow-k]
		+ 当初始时,若[fast] != [slow-k]
			说明[slow-k]到[fast]不连续
			+ 令[slow] = [fast],同时使[slow]与[fast]向后遍历相同长度
				使得[fast]与[slow]与[slow-k] 可以查找下一段超过k的相同数字
				直到使[fast] == [slow-k]
