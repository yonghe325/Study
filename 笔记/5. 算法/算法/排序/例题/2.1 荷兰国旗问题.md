给定一个数组arr，和一个数num
请把小于等于num的数放在数组的左边，大于num的数放在数组的右边
要求额外空间复杂度0（1)，时间复杂度0(N)
```
#include "head.h"
void sortColors(int*arr,int length,int num) {
	//双指针
	int left = 0;
	int right = 0;
	int mid = 0;
	for (size_t i = 0; i < length; i++)
	{
		if (arr[right]<=num) {
			mid = arr[left];
			arr[left] = arr[right];
			arr[right] = mid;
			left++;
		}
		right++;
	}
}
```
