# 一级指针变量
```
int a = 10;
int* pa = &a;
*pa = 20;
printf("%d\n", a);
```
pa是==指针变量==,即==一级==指针变量
# 二级指针变量
```
int a = 10;
int* pa = &a;
*pa = 20;

int** p_pa = &pa;
**p_pa = 30;
//将a赋值为30
printf("%d\n", a);
```
p_pa也是指针变量,为二级指针变量
***二级指针 只能用来存放 一级指针变量的地址***

# ***二级指针 指向的 指针数组的连续性***
转到指针数组[[指针数组]]
```
int* a,b,c
int* arr[3]={a,b,c};
int** pa =arr; 
```
其中
虽然
a\[0] == a,...
但
==a,b,c的地址不一定连续==
但
==a\[0],a\[1],a\[2] 的地址一定连续==
