# strerrno(errno) 查看错误码
当程序异常时,errno将会覆写为当前错误的错误码
strerrno则将错误码转为对应的字符串
通过
```
print("%s\n",strerrno(errno));
```
则可打印出错误信息
# perror("<提示信息>") 打印错误信息
类似于strerrno(errno)
但perror会直接打印出错误信息
而<提示信息>将会在错误信息开头被打印出
类似于
```
perror("这里错了");
//输出
这里错了 : <错误信息>
//会自动加加上一个 " : "
```
相当于
```
print("这里错了 : %s",strerrno(errno));
```
