# 一维数组
数组名一般表示首元素地址
但又两个例外
1.sizeof(数组名），这里的数组名表示整个数组，计算的是整个数组的大小，单位是字节
2.&(数组名)，这里的数组名表示整个数组，取出的是==整==个数组的地址

# 二维数组
二维数组的数组名仍然表示==该二维数组的首元素地址==
# 数组名与 & * 的结合
分为
+ 行指针  : int(\*)\[n]
+ 数组指针 : int(\*)\[m]\[n] 
+ 普通指针 : int*
+ 普通int类型 : int
## 一维数组
```
int a[5];
a
*a
&a
a[1]
*a[1]
&a[1]
```
## 二维数组
```
int a[5][5];

a      int(*)[5] 第一行的地址
	+1跳过一行,指向第二行的首地址
	== &a[1]
*a     int* 第一行第一个元素的地址
	+1指向第一行第二个元素的地址
	==&a[0][1]
&a     int(*)[5][5] 整个二维数组的地址
	+1指向整个二维数组的下一个地址
a[1]   int[5] 第二行一维数组本身
	+1指向第一行第二个元素的地址
*a[1] int 第二行第一个元素的值
	+1表示对 第二行第一个元素的值 +1
	==a[1][0]+1
&a[1] int(*)[5] 第二行的地址
	+1指向第三行(越界)
*a[1][1] 错误
	+1异常
&a[1][1] int* 第二行第二个元素的地址
	+1指向第二行第三个元素的地址
```
