# 声明
``` 
struct tag
{
	member-list;
}variable-list;
```
struct : 为结构体声明关键字
tag : 为该结构体标识符
{} : 里为成员列表
variable-list : 为变量列表

```
struct Peo
{
	char name[10];
	char tel[12];
	char sex[5];
	int high;
};
int main()
{
	struct Peo p1 = { 0 };
	//创建Peo变量p1,并初始化
	return 0;
}
```
声明,初始化结构体
结构体之间可以嵌套
```
struct Peo
{
	char name[10];
	char tel[12];
	char sex[5];
	int high;
};

struct Stu
{
	struct Peo p1;
	int num;
};
```
