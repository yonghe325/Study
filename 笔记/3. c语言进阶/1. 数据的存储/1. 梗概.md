# 类型的基本归类
## signed 与 unsigned
```
int a = 10;
```
a是一个整形,有符号(signed)的整形
一个int型是4个byte
认为最高位是符号位,不是有效位,不决定值
0表示正数
1表示负数

+ 在生活中,有些值没有负数
例如 : 身高,重量...
就可以使用unsigned类型
最高位就变成有效位
```
int a = 10;
```
a是一个整形,有符号的整形,一个整形是4个byte
认为最高位是符号位,不是有效位,不决定值
0表示正数
1表示负数
