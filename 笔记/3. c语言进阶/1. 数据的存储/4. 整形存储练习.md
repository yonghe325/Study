# char类型原反补整形提升
==截断行为在存储时发生==
==整形提升行为在输出时发生==
```
#include<stdio.h>
int main() {
	char a = -1;
	signed char  b = -1;
	unsigned char c = -1;
	printf("%d,%d,%d", a, b, c);
	return 0;
}
# 输出 ? 
a = -1
b = -1
c = 255

 
```
## a = -1
1. 截断 
+ (整形)-1的原反补 :
10000000 00000000 00000000 00000001
11111111 11111111 11111111 11111110 
11111111 11111111 11111111 11111111
+ 强制类型转换后,取低序字节
a =  (补码)11111111 
2. 打印
+ 以%d(打印有符号的整形)的方式打印
***整形提升***
==补码==高位全部补符号位
负数补1
11111111 111111111 111111111 11111111
取反+1得到原码
10000000 00000000 00000000 00000001
即为 ==-1==
## b = -1
原理同a相同
## c = 255
1. 截断 
+ (整形)-1的原反补 :
```
10000000 00000000 00000000 00000001
11111111 11111111 11111111 11111110 
11111111 11111111 11111111 11111111
```
+ 强制类型转换后,取低序字节
c(无符号char型) =  (补码)11111111
2. 打印
+ 以%d(打印有符号的整形)的方式打印
***以无符号整形提升***
正数补0
==补码高位全部补0==
补码 : 
00000000 00000000 00000000 11111111
正数原反补相同
打印
c = 255
# 整形提升无符号数
```
int main() {
	char a = -128;
	printf("%u\n", a);
	return 0;
}
```
```
1. -128(有符号整形) 原反补
	原 : 100000000 00000000 00000000 10000000
	反 : 111111111 11111111 11111111 01111111 
	补 : 111111111 11111111 11111111 10000000
2. 截断
	取低字节序第一个字节
	char a = 10000000
3. 整形提升 
    %u打印无符号十进制整形,
    -128有符号,高位补符号位
    补 : 111111111 11111111 11111111 10000000
    正数原反补相同
4. 打印 
   以十进制打印
 
```

# char类型死循环01
```
int main() {
	unsigned int i;
	# i的值一定 >= 0
	for(i = 9;i >=0;i--)
	{
		printf("%u\n",i);
	}
	return 0;
}
```
i的取值 : 
```
9 8 7 6 5 4 3 2 1 0 4294967295 .... 
```
+ 原因 : 
i一直减 1
当i = 0 时,减1等于 (-1)
因为i是unsigned int类型
-1被解释为正数
1. 导致
-1补码 : 
111111111 111111111 111111111 111111111
被以当做无符号整形看待
2. 导致
4294967295原码反码补码:
111111111 111111111 111111111 111111111
即输出4294967295

# char类型死循环02
```
int main() {
	char a[1000];
	int i;
	for ( i = 0; i < 1000; i++)
	{
		a[i] = -1 - i;
	}
	printf("%d\n", strlen(a) );
	return 0;
}

现象 : 
a[0] = -1
a[1] = -2
...
a[127] = -128
	char类型-128补码 :
	1000000 
a[128] =127
	char类型127补码 :
	1111111
a[129] = 126  
	char类型126补码 :
	1111110
...
a[..] = 1
a[..] = 0
a[..] = -1
...
a[..] = -128
..
循环
```
