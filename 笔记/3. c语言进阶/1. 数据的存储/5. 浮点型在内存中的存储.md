# 浮点数存储规则
==IEEE 的 754标准==
任何一个二进制浮点数V可以被表示为以下格式 : 
V = (-1)^S \* M * 2^E 
+ (-1)^S 表示符号位
当S = 0,V为正数
当S = 1,V为负数
+ M表示有效数字
大于等于1
小于2
+ 2^E 表示指数位
例如 : 
1. 浮点数 V = 5.0f
 +  转化为二进制 : 
 101.0
 +  转化为指数形式
 1.01\*2\^2
 +  加上符号
 (-1)^0 \* 1.01 \* 2\^2
2. 浮点数V = 9.5f
 + 转化为二进制
 1001.1
 +  转化为指数形式
 1.0011 \* 2^3
 +  加上符号
 (-1)^0 \* 1.0011 \* 2^3
# 精度丢失
当V = 9.6f时
+ 转化为二进制
1001.10000000...
由于小数点后数位不是0.1的整数倍
转化为二进制时,总是会寻找最接近的数位
+ 例如 : 
9.6
= 1001.1 = 9.5<9.6
=1001.101 = 9.5+0.125>9.6
=1001.1001 =9.5 + 0.125/2 <9.6
...
+ 然而float,double类型内存字节大小有限
浮点数无法精确保存

# 精确保存
## IEEE 754规定 : 
==阶码(e)大小决定范围
数位位数(m)决定精度==
+ 对于32位(4个字节float)的浮点数
分为三个区域分别保存
S E M
1 8 23
![[浮点数保存.png]]
+ 对于64位(double)的浮点数
S E  M
1 11 52

# IEEE特别规定(SME存放细则)
## 有效数字1<=M<2
m可以写成1.xxxxx
xxxx为小数部分
当计算机内部保存M时,==默认M总是1==
因此可一直保存xxxxx部分
这样做可以节省1位内存
当读取的时候,再把1加上
+ 在32位的浮点数上,可以保存24位的有效数字
+ 在64位的浮点数上,可以保存53位的有效数字
## 指数E
### 存入
IEEE规定
指数E为一个无符号整数(unsigned int)
这意味着
+ 在32位浮点数中,E为8位,取值范围为0~255
+ 在64位浮点数中,E为11位,取值范围为0~2047
---
==但E可以表示负数==
所以IEEE 754 规定
存入内存时E的真实值必须再加上一个==中间数==
==通过移码,强行让负数合法==
+ 对于8位的E来说
中间数为 127
+ 对于11位的E来说
中间数 1023
#### 样例 
1. V = 0.5(十进制)
  =0.1(二进制)
  =1.0 \* 2^-1
  = (-1)^0 \* 1.0 \*2^-1 
  S = 0    M = 1.0     E = -1 此时E为负数
 即在内存的8个字节中存入 (E + 127) = ==126== 
2. V =  5.5
 ```
 float f = 5.5;
 // 5.5
 // 101.1
 //1.011 * 2^2
 //s=0 m=1.011 e=2
 // 
 //s  e=2 + 127   m 不放入整数 1 
 //0  10000001    01100000 00000000 0000000
 //01000000 10110000 00000000 00000000
 //40       b0       00       00
 //小端字节序放入内存
 ```
 ![[浮点数存储.png]]
3. 2^10 的E是10,所以保存为32位浮点数时必须保存成
  10+127 = 137 即
  存入10001001
### 取出
取出分为三种情况
#### E 不全为0 或 不全为1 ==最常见==
1. 将阶码(指数e)的计算值减去127(或1023)得到真实值
2. 将有效数字M前加上第一位的1

例如 : 
0.5的内存数值为
0 01111110 00000000000000000000000
s e=-1+127=126          m
#### E 为全0
1. 直接将e的真实值赋值为1-127 或 1-1023
2. m不再加上第一位的1
 而是还原为0.xxxxx小数
 这样做是为了表示+-0,以及无限接近于0的很小的数字
#### E为全1 
1. 有效数字m全为0,表示+-无穷大(正负取决于符号位)

# 样题解释
```
int main() {
	int n = 9;
	//00000000 00000000 00000000 00001001

	float* pFloat = (float*)&n;

	printf("n的值为: %d\n", n);
	//以%d的形式打印

	printf("*pFloat的值为 : %f\n", *pFloat);
	//浮点数的规则解读n的二进制值
	//0 00000000 00000000000000000001001
	// s=0  e=0 m=0.00000000000000000001001
	//即为
	//+0.0.00000000000000000001001 * 2^-126
	//无限接近于0
	//打印0.0000000
	// 
	
	
	printf("*pFloat的值为 : %f\n", *pFloat);
	//printf("%d\n", 0x411000);
	*pFloat = 9.0;
	printf("num的值为: %d\n", n);
	printf("*pFloat的值为 : %f\n", *pFloat);
	return 0;
}
```
