# 整形的二进制也有三种表示形式
每四个二进制位由一个十六进制数表示
```
int a = 10;
原 : 00000000 00000000 00000000 00010100
	0x 00 00 00 14
反 : 00000000 00000000 00000000 00010100
	0x 00 00 00 14
补 : 00000000 00000000 00000000 00010100
	0x 00 00 00 14

int b =-10;
原 : 10000000 00000000 00000000 00001010
	0x 80 00 00 0a
反 : 11111111 11111111 11111111 11110101
	0x ff ff ff f5
补 : 11111111 11111111 11111111 11110110
	0x ff ff ff f6
```
1. 正整数
原码,反码,补码相同
2. 负整数
原码,反码,补码需要计算得出
+ 原码 :直接通过正负的形式写出的二进制序列
+ 反码 : 原码的符号位不变,其他位按位取反
正数符号位 = 0
负数符号位 = 1
+ 补码 : 反码 + 1就是补码
# 数据在内存中一律只存储数据的补码
使用补码
+ ==***可以将符号位和数值域统一处理***==
加减法也可以统一处理(cpu只有加法)

+ 补码与原码相互转换,其运算过程是相同的
不需要额外的硬件电路
==原码 ---> 取反原码 + 1 = 补码
补码 ---> 取反补码 + 1 = 原码

## 计算加法
```
# 十进制
1-1
1+(-1)

# 二进制原码
00000000 00000000 00000000 00000001
+
10000000 00000000 00000000 00000001

# 二进制补码
00000000 00000000 00000000 00000001
+
11111111 11111111 11111111 11111111
=
00000000 00000000 00000000 00000000 = 0
```
