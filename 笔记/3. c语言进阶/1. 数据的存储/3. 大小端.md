本质是数据以==字节==为单位
==字节序==在内存中的存放顺序
与位段的存储无关 : 位段以bit为单位进行开辟
# 大端字节序存储 : 由低向高
把 ==高位字节序的内容== 放在==低地址==处
把 低位字节序的内容 放在高地址处

0x 11       22      33        44
高位字节                 地位字节
+ 存放时
11       22       33      44
低地址                     高地址
# 小端字节序存储 : 由高向低
把 ==高位字节序的内容== 放在==高地址==处
把 低位字节序的内容 放在低地址处

0x 11       22      33        44
高位字节                 地位字节
+ 存放时
44      33       22      11
低地址                     高地址
# 检测大小端
## 取地址解引用 
```
int check_sys() {
	int i = 1;
	return (*((char*)&i));
}
```
1. & 取地址符取出起始地址
取地址顺序为 : 
==从低地址向高地址取==
3. i 变量申请4个字节
+ &i 取出i变量的 地址
+ (char*) 只取一个字节的地址,
(char*)&i 代表取出i变量申请地址的第一个字节
+ \*(char*)&i 解引用==i变量地址的第一个字节==

==如果为 0 则为大端
如果为 1 则为小端==
