# 二维数组 传址打印
==用一个二维数组来接收==
```
//形参部分写数组
void print1(int arr[3][5],int r ,int c ){
int i =0;
for(i=0;i<r;i++){
	int j =0;
	for(j =0;j<c;j++){
		printf("%d ", arr[i][j])
	
	}
	printf("\n");
}
}

# 数组指针 
***该方法可以直接改变实参数组的值***
==二维数组的首元素地址是它的***第一个一维数组整体***==
***用一个指向一维数组的指针来接收***
```
此时
void print2( int (*p)[5],int r ,int c ){

//此时*p代表第一个一维数组 的 首元素地址
//*(p+1)代表第二个一维数组 的 首元素地址
//*(p+2)代表第三个一维数组 的 首元素地址
//*(p+i) 等价于 p[i]
for(i=0;i<r;i++){
	int j =0;
	for(ij0;ijc;j++){
	
		printf("%d ", *(*(p+i)+j))
		//或者
		printf("%d ", p[i][j])
		
		
		//*(p+i)+j 代表 第i个一维数组 的 第j个元素的 地址
		//*(*(p+i)+j)代表 第i个一维数组 的 第j个元素
		
		
	}
	printf("\n");
}
}
