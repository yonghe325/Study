# 数组指针
本质上是指针
整形指针 -> 指向整形的指针
字符指针 -> 指向字符的指针 
指针数组 -> 指向指针变量的数组

==数组指针 -> 指向数组的指针==
数组指针存放 整个数组的地址
```

int *p1[10] = {指针1,指针2,指针3,...};
//p1是指针数组
//p1与[10]结合
//p1是数组名

int (*p2)[10];
//p2时数组指针
//p2与*结合
//p2可以指向一个数组,该数组有10个元素,每个元素是int类型


```
==char* (\*p3)[5];
//表示p3指向有5个元素的数组
//每个元素为char\*类型==

p1为指针名
类型为 int* 表示指向一个变量

p2为数组指针名
类型为 int (\*)\[10] 表示指向10个元素的数组(整个数组)
其本质上应写为
***int (\*)\[10] p2 = &arr;***
java使用此写法

 --- 
int arr\[10] ={0};
int* p1 =arr;
p1存放arr数组首元素地址

int (\*p2)\[10] = &arr;
\*p2 指向 整个arr数组 即首个元素的地址 ==此时的\*不表示解引用==
\[10] 表示 arr数组 有10 个元素
int 表示 arr数组 存放 int类型的元素
# 指针数组 书写要求
```
int (\*p2)\[10] = &arr;

// []内必须有正整数

```

# 再次讨论数组名
转到[[数组名]]
```
int main() {
	int arr[10] = {0};
	printf("%p\n", arr);
	printf("%p\n", &arr[0]);
	printf("%p\n", &arr);

	int sz = sizeof(arr);
	printf("%d\n", sz);
	return 0;
}
```

数组名通常表示首元素的地址
但又两个意外 : 
1. sizeof(数组名)
 sizeof()里单独放一个数组名
 计算整个数组的大小
 2. &数组名
***取出的是==整==个数组的地址***
![[数组名02.png]]
+ arr
 arr表示首元素地址 ,是 int* 类型 
 \+ 1 跳过4个字节
+ &arr
 \+1 跳过整个数组
+ &arr\[0]
 arr\[0]==取地址之后== 是 int* 类型
  \+ 1 跳过4个字节
