# 二维数组
```
int a[3][4] = { 0 };
```
a表示整个二维数组的首元素 , 即 第一个一维数组的地址
为一个 数组指针变量
所以 : 
a+1 表示 第二个一维数组 的地址
**\*(a+1) <==> a\[1]**
a\[0/1/2/3] 表示 每个一维数组 的 第一个元素的地址
即 **a\[0]<==> &a\[0]\[0]**

---
```
	printf("%d\n", sizeof(a));
48
```
a为二维数组的数组名
此时表示整个数组的大小

---
```
	printf("%d\n", sizeof(a[0][0]));

```

```	
	printf("%d\n", sizeof(a[0]));
16
```
a\[]表示每个一维数组的 数组名
数组名==单独==放在sizeof()内
表示计算整个数组元素的大小

---
```
	printf("%d\n", sizeof(a[0]+1));
16
```
a\[0]没有单独放在sizeof()内部,也没有取地址
此时a\[0]表示 ==首个一维数组 的 首个元素 的地址==
+1表示 ==第一个一维数组 的 第二个元素 的地址==

即第一个一维数组的整个地址

即一个 ==数组指针变量==
