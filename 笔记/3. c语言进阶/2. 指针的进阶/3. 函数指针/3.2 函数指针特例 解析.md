# void 类型
解释以下代码
## 第一个
```
(*(void(*)())0)();
```
### 个人理解
1. void(\*)() : 函数指针变量
返回值 为 void
函数名 为 NULL
形参 为 void
2. \*(void(\*)()) :函数地址
解引用 函数 NULL
3. \*(void(\*)())0
==0 不知道啥意思???==
4. (\*(void(\*)())0)() : 使用函数
 该函数无形参
### 实际解释
==以上代码试一次函数调用
调用的是0作为函数地址处的函数==
1. void(\*)() : ==函数指针类型==
类似于 int* ,char*
2. void(\*)() 0 : ***强制类型转换*** , 成为一个函数地址
将 0 强制类型转换为 
***==无参 , 返回类型是void的函数的地址==***
0 处可以是 任何地址
此时改地址被认为是一个函数
3. \*void(\*)() 0 : 加\*号调用函数
==可以不加\*号==
4. (\*(void(\*)())0)() : 调用函数 , 不传参
# 第二个
```
void (*signal(int,void(*)(int)))(int);
```
## 个人理解
1. void(\*)(int) : 函数指针类型
返回值 为 void
形参类型 为 int
2. signal( int , void(\*)(int) )
signal作为函数名
形参为 int类型 与  void(\*)(int) 类型
3. \*signal( int , void(\*)(int) ) : 解引用signal函数
此时signal为函数名
4. void (\*signal(int,void(\*)(int))) (int) :定义函数指针
返回值 为 void
形参 为 int类型
## 实际解释 
==以上代码时一次函数***声明***==

==本质上是
+ 声明一个函数名为 signal 
+ 形参为 int类型  与 void(\*)(int)函数指针类型
+ 返回值为 void (\*)(int) 函数指针类型==
### 第一部分 :
```
 signal(int,void(\*)(int))
```
1. void(\*)(int) : 函数指针类型
返回值 为 void
形参类型 为 int
2. signal( int , void(\*)(int) )
signal作为函数名
形参为 int类型 与  void(\*)(int) 类型
### 第二部分 :
```
void (*)(int);
//函数指针类型
```
该部分作为类型
成为 函数signal 的返回类型
## 实现以上代码的的更优解

typedef void(*pf_t )(int);

//声明函数
pf_t signal(int,pf_t){

	return pf_t(4);
