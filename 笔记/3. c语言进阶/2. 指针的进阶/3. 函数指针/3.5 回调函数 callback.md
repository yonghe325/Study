==回调函数就是一个通过函数指针调用的函数==
如果你把函数(A)的指针 (地址) 作为参数传递给另一个函数(B)
当这个指针被用来调用其所指向的函数时
==即 在B函数内部 通过指针 调用A函数==
这就是回调函数

回调函数不是有该函数的实现方直接调用
而是在特定的 事件 或 条件 发生时 由另一方调用的
用于对该事件或条件进行相应
```
#include<stdio.h>
int Add(int x, int y) {
	return x + y;
}
int Sub(int x, int y) {
	return x - y;
}
int Mul(int x, int y) {
	return x * y;
}
int Div(int x, int y) {
	return x / y;
}
void muen() {
	printf("*************************************\n");
	printf("***********1.Add    2.Sub     *******\n");
	printf("***********3.Mul    4.Div     *******\n");
	printf("***********0.end              *******\n");
	printf("*************************************\n");
}

void calc(int(*pf)(int, int)) {
	int x = 0;
	int y = 0;
	int ret = 0;
	printf("请输入两个操作数 : \n");
	scanf_s("%d %d", &x, &y);
	ret =pf(x, y);
	printf("%d\n", ret);
}

int main() {
	int input = 0;
	do {
		muen();
		printf("请选择运算 : \n");
		scanf_s("%d", &input);
		switch (input) {
		case 1:
			calc(Add);
			break;
		case 2:
			calc(Sub);
			break;
		case 3:
			calc(Mul);
			break;
		case 4:
			calc(Div);
			break;
		case 0:
			printf("退出运算\n");
			break;
		default:
			printf("输入错误,重新输入\n");
			break;
		}
	} while (input);
	return 0;
}
```
此时calc函数为外部函数
通过在其内部 通过指针 调用add等函数
