类似于 数组指针
数组指针 -> 指向一个数组的指针
==函数指针 -> 指向一个函数的指针==(指向函数的入口地址)
==遵循：先有函数，后有指针==
函数一旦被定义,就有地址
存放在内存 中的 代码区
函数指针 无法被运算
# 函数名的意义
&函数名 取出 函数的地址
![[函数指针.png]]
对于函数来说
指向函数的入口地址
&函数名 与 函数名 都表示 函数的地址()
# 函数指针==类型==的书写规则
```
<返回类型> (*)(<形参1类型>,<形参2类型>,<形参3类型>...)
```
以上只是一个类型
==定义了一个 
返回值为 <返回类型>
形参为 (<形参1类型>,<形参2类型>,<形参3类型>...)
的 一个函数指针类型==
# 函数指针的赋值规则
```
int ADD(int a, int b) {
	return a + b;
}
	
	int (*pf)(int,int) = &ADD;
	
	printf("&ADD = %p\n", &ADD);
	printf("ADD = %p\n", ADD);
	printf("pf = %p\n", pf);
```
![[函数指针的赋值.png]]

```
 <函数返回类型> (*<变量名>)(函数形参1的类型,函数形参2的类型,函数形参3的类型..) = &函数名
 例 :
 int ADD(int a, int b) {
	return a + b;
}

int (*pf)(int,int) = &ADD;
int (*pf)(int,int) = ADD;
```

# 函数指针 的 使用 -> 回调函数

函数指针 解引用 可以找到函数
通过解引用可以使用函数
```
int ret = (*pf)(2,3);
//或
int ret = pf(2,3);
//*号可以不写
//或
int ret = (*ADD)(2,3);
//ret = 5
```
# 函数指针存在的意义
```
int ADD(int a, int b) {
	return a + b;
}

void calc(int (*pf)(int,int)){
	int a= 3;
	int b= 2;
	printf("%d\n",pf(a,b));
}
int main(){
	calc(ADD);
	return 0;
}
```
