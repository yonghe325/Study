# 字符指针的赋值
```
char* p = "abcdef";
char arr[] = "abcdef";
printf("%s\n", p); 
//输出abcdef
```
任何一个变量由它的
==类型属性,值属性决定==
解释上述代码 :
+ 赋值
 "abcdef"实际上是一个值(值属性)
 指针p实际上被赋予(托管)该值的首元素(a)的元素的值==地址==
 数组arr才被赋予"abcded"
+ 打印
 %s打印字符串
 通过p向%s提供首元素的地址
 %s向后打印,当检测到==\0==时,停止打印
+ 隐患
 由于=="abcdef "是一个常量字符串,不能被修改== 
 通过\*p(char\* 类型)可以修改首元素(a)的值
 导致异常
 ```
 char* p = "abcdef";
 *p = 'w';
 printf("%s\n", p); 
 //异常
 ```
 可以通过const修饰指针p,限制指针p不能被修改
 避免此异常
 ```
 const char* p = "abcdef";
 *p = 'w';
 printf("%s\n", p); 
 //没问题
 ```
# 字符指针的关系运算
```
	const char* p1 = "abcdef";
	const char* p2 = "abcdef";

	char arr1[] = "abcdef";
	char arr2[] = "abcdef";

	if (p1 == p2)
	{
		printf("p1 == p2\n");
	}
	else
	{
		printf("p1 != p2\n");
	}
	if (arr1 == arr2)
	{
		printf("arr1 == arr2\n");
	}
	else
	{
		printf("arr1 != arr2\n");
	}
//输出
//p1 == p2
//arr1 != arr2
```
解释 : 
+ p1,p2指向同一个常量字符串"abcdef"的同一个首元素的同一个地址
 常量字符串,无法修改,为只读
 由于常量字符串"abcdef"无法修改
 所以在==内存中只存储了一个 "abcdef" 常量 ==
 所以p1,p2 指向的地址相同
 所以p1 == p2
+ arr1,arr2两个分别被创建
分别给予了两个地址空间
数组名arr1,arr2实际上是两个指针
所以arr1,arr2比较的是地址
所以arr1 != arr2
