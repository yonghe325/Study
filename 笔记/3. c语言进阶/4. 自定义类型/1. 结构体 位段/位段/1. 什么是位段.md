位段与结构体类似
位段是一种 节省空间 的做法

# 声明
```
struct <位段名>{
	int <标识符1>:x1;
	int <标识符2>:x2;
	int <标识符3>:x3;
	int <标识符4>:x4;
}
```
+ 位段与结构体类似,都有成员变量
	+ 位段的成员变量只能是整形,即:
		+ int
		+ unsigned int
		+ signed int
		+ char
	+  位段的成员变量后面必须加上 '' : ''
	+ '' : ''后面必须加上一个正整数
		+ 正整数表示该变量在内存中占用几个==bit位==

## 例如
```
struct A{
	int _a:2;
	int _b:5;
	int _c:10;
	int _d:30;
}
```
A就是一个位段类型
+ int \_a:2;
	+ 表示变量_a只占用2bit位
+ int \_b:5;
	+ 表示变量_b占用5bit位
# 使用场景
实际写代码时
有些变量的取值很小
位段还涉及很多不确定因素,位段是不跨平台的
注重可移植的程序应避免使用位段
例如 : 
+ flag判断真假
	+ flag = 0时,为假
	+ flag = 1时,为真
	+ 此时flag只需要1bit位
