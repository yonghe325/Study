# 位段的内存分布
位段的空间是按照需要以4个字节或者1个字节的方式来开辟的
```
struct S {
	char a : 3;
	char b : 4;
	char c : 5;
	char d : 4;
};
```
+ 解释:
```
struct S {
	char a : 3;
//占3个bit位
//分配一个字节
//该字节还剩余5个bit位
	char b : 4;
//占4个bit位
//由于a所占字节还剩余5bit位
//b只占4bit位
//所以b直接在a所在字节存放,占用4bit位
//此时a,b所在字节还剩余1bit位
	char c : 5;
//占5个bit位
//a,b所在字节还剩余1bit位
//无法存放c
//所以c新开辟一个字节
//c占用新开辟的字节的5bit位
	char d : 4;
//占4个bit位
//c所在字节剩余3bit位
//无法存放d
//因此d新开辟一个字节
//占用新字节的4bit位
};
```
# 使用
```
#include<stdio.h>
struct S {
	char a : 3;
	char b : 4;
	char c : 5;
	char d : 4;
};

int main() {
	struct S s = { 0 };
	s.a = 10;
	s.b = 12;
	s.c = 3;
	s.d = 4;
	return 0;
}
```
位段的数据在内存存放 时
不遵循大小端字节序
==直接从左向右放入该字节中==

## 存放s.a
1. 开辟空间
```
0000 0000
```
2. 放入a = 10
	+ 由于s.a = 10 = 0b 1010
		存放s.a需要占用4bit位
		位段只为a开辟了3bit位
		无法完全放入s.a
	+ 截断s.a
		从s.a的数位低位向高位 ==截取== a对应开辟的bit位数
		即 3bit为
		所以s.a实际存入了0b010 
## 存放s.b
1. 查看s.a所在字节的剩余bit位数是否足够放入s.b
```
a所在字节 = 
00000 010
```
2. 放入s.b
	+ s.b = 12 = 0b 1100
		存放s.b需要占用4bit位
		位段为b开辟4bit位
		足够放入s.b
## 存放s.c
1. 查看先前定义的变量所以在的字节剩余比特位是否足够c的开辟
```
a,b所在字节 = 
0 1100 010
```
剩余1bit位,不够c的开辟
2. 重新为c开辟一个新的字节'
```
01100010 00000000
```
3. 放入s.c
	+ s.c = 3 = 0b 011
		存放s.c需要占用3bit位
		位段为c开辟5bit位
		足够放入s.c
## 存放s.d
1. 查看先前定义的变量所以在的字节剩余比特位是否足够d的开辟
```
00011010 000 00011
```
剩余3bit位,不够d的开辟
2. 重新为d开辟一个新的字节
```
00011010 00000011 00000000
```
3. 放入s.c
	+ s.d = 4 = 0b 100
		存放s.d需要占用3bit位
		位段为d开辟4bit位
		足够放入s.d
