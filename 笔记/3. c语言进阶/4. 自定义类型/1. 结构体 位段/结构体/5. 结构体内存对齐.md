#  引入 : 计算一个结构体的大小
```
struct s1
{
	char a1; 
	int i;
	char c2;
};
			// 12byte
struct s2
{
	char a1;
	char c2;
	int i;
};
			// 8byte
struct s3
{
	char a1;
	int i;
};
			// 8byte
struct s4
{
	char a1;
	int i;
};
			// 8byte
```
发现一个结构体中:
+ 定义不同的类型时,结构体的大小不同
+ 定义相同的类型时,变量定义的顺序不同,结构体的大小不同

# 结构体的对齐规则
+ 第一个成员变量在 结构体变量 ==偏移量为0的地址处==
+ 其他成员变量要对齐到某个数字(对齐数)的整数倍的地址处
```
对齐数 = (编译器默认的一个对齐数 与 该成员变量类型大小) 之间的的较小值
//vs 中的默认值为 8
例如 : int 类型为4字节 , 编译器默认值为 8
	则取较小值4为对齐数 
```
+ 结构体总大小 为 
	+ 最大对齐数(每个成员变量都有一个对齐数) 的整数倍  
	+ 且包含所有成员变量的地址的 最小数
+ 当结构体嵌套时,嵌套的结构体对齐到自己最大对齐数的整数倍处
结构体的的整体大小就是所有最大对齐数(含嵌套结构体的对齐数)的整数倍

##  c库宏 : offsetof() : 查询结构体中成员变量的偏移量
```
offsetof(type,member);
```
返回 一个size_t类型,为成员变量的偏移量
```
#include <stddef.h>
#include <stdio.h>

struct address {
   char name[50];
   char street[50];
   int phone;
};
   
int main()
{
   printf("address 结构中的 name 偏移 = %d 字节。\n",offsetof(struct address, name));
   
   printf("address 结构中的 street 偏移 = %d 字节。\n",offsetof(struct address, street));
   
   printf("address 结构中的 phone 偏移 = %d 字节。\n",offsetof(struct address, phone));

   return(0);
}
//address 结构中的 name 偏移 = 0 字节。
//address 结构中的 street 偏移 = 50 字节。
//address 结构中的 phone 偏移 = 100 字节。

```
# 内存对齐的意义
拿空间换取时间
1. 平台移植
不是所有硬件平台能够访问任意地址的任意数据
某些硬件平台只能在某些特定地址处粗的特定类型的数据
否则抛出异常
2. 性能原因
数据结构(尤其是栈)应该尽可能的在自然边界上对齐
原因在于,为了访问未对齐的的内存,处理器需要做两次内存访问
而对齐内存只需要访问一次
# 优化结构体
既要满足对齐,又要节省空间
+ 非必要情况下,尽量让小的类型集中在一起定义

# \#pragma pack() 修改对齐数
通过#pragma与处理指令,使用pack(),将默认对齐数修改
```
#pragma pack(16)
//将默认对齐数修改为16
#pragma pack(1)
//将默认对齐数修改为1
#pragma pack()
//重置默认对齐数为8
```
