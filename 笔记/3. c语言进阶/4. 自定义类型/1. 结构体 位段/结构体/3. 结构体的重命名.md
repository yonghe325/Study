# 结构体重命名
```
typedef struct Str_name{
	int data;
	struct Str_name* next;
}re_Str_name;
```
此时
```
struct Str_name n1;
//相同
re_Str_name n2;
```
# 结构体指针重命名
```
typedef struct Node{
	int data;
	struct Node* next;
}* linklist ;
// 同时定义结构体Node并 将其指针重命名为linklist
```
或
```
struct Node{
	int data;
	struct Node* next;
};
//定义结构体Node
typedef struct Node* linklist;
//然后将其 指针类型 重命名为linklist
```
将 Node结构体的指针重命名为linklist
