结构体是多种不同类型变量的集合
```
struct tag{
	member_list;
}varible_list;
```
类型创建的位置决定了其是全局变量还是局部变量
# member_list
存放多种不同类型
# varible_list
代表用上述结构体创建的变量
```
struct stu{
	char[5] name;
	int age;
}s1,s2,s3;
```
s1,s2,s3即使用stu类型创建的变量
# 声明 + 定义
+ 定义全局变量S1,S2,S3
```
struct stu{
	char[5] name;
	int age;
}s1,s2,s3;
int main(){
	return 0;
}
```
+ 定义局部变量s1,s2,s3
```
struct stu{
	char[5] name;
	int age;
};
int main(){
	struct s1,s2,s3;
	return 0;
}
```
## 特殊声明
+ 匿名结构体声明 : 省略结构体标签,临时使用
```
struct {
	char[5] name;
	int age;
}s1;
int main(){
	return 0;
}
```
在声明时同时创建变量
==只能使用一次==
编译器无法判断匿名结构体类型
导致结构体的指针无法使用
