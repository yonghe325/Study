```
struct Node{
	int data;
	struct Node next;
};
```
错误,  无法计算结构体大小
```
struct Node{
	int data;
	struct Node* next;
};
```
此时一个Node类型能找到下一个Node类型
即 自己能够找到与自己同类型的一个节点
则 Node能实现链表的功能 , 称为自引用
则此时结构体Node为一个节点 转到[[2. 链表]]
Node节点分为两个域
+ 数据域 : 存放数据
+ 指针域 : 存放下一个节点的地址

# 特殊
## 匿名结构体无法实现自引用
```
typedef struct {
	int data;
	Node* next;
}Node;
//不支持
```
无法实现自引用
