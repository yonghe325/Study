# 枚举的意义
总有些变量的取值可以被一一列举
例如 : 
+ 周一,周二...
+ 性别 : 男,女,保密
+ 月份
+ 三原色 : 红绿蓝

而枚举就是指将所有可能的取值一一列举
枚举本质是一个类型,当声明一个枚举时,不为该枚举分配空间
只有当被定义时,才开辟空间
限制变量取值为 被枚举 的取值
# 枚举的定义
```
//星期
enum Day {
	Mon,
	Tues,
	Wed,
	Thur,
	Fri,
	Sat,
	Sun
};

//性别
enum Sex{
	MALE,
	FEMALE,
	SECRET
};
...
```
与结构体类似
枚举由 标识符 与 ==枚举常量== 组成
# 枚举常量的值
枚举常量赋不能被修改,只能为其赋初始值
## 默认值
枚举常量都有其默认得值
第一个为 0 
第二个为 1
....
