# 增加代码的可读性及维护性
# 和#define定义的标识符比较,枚举有类型检查,更加严谨
## 在C环境下
由于c语言对枚举变量的类型检查不严格
可以为直接为 枚举变量 赋值 为一个数字
此时,该枚举变量就被赋值为该数字对应的枚举常量
```
enum Day {
	Mon,//0
	Tues,//1
	Wed,//2
	Thur,//3
	Fri,//4
	Sat,//5
	Sun//6
};
int main() {
	enum Day d = 4;
	//相当于
	// enum Day d = Fri;
	return 0;
}
```
## 在C++环境下
c++语言对枚举变量的类型检查更严格
==不能直接==为 枚举变量 赋值 为一个数字
只能赋值为该枚举类型中的枚举常量
```
enum Day {
	Mon,//0
	Tues,//1
	Wed,//2
	Thur,//3
	Fri,//4
	Sat,//5
	Sun//6
};
int main() {
	enum Day d = Fri;
	//只能这样赋值
	return 0
```
