```
char *strcpy( char *dest, const char *src );
```
复制 `src` 所指向的空终止字节字符串，包含空终止符，到首元素为 `dest` 所指的字符数组。
+  char \*dest
接受 复制的数组 的首元素地址
==若dest指向的数组未定义== , 则显示异常
==dest只能指向字符数组==,否则 异常
==dest指向的数组必须足够大==,以确保能存放原字符串
==dest指向的数组空间必须可变==,不能为常量
+ char \*src
被 复制的数组 首元素地址
==src只能指向 以'\0' 即终止字符 结尾的字符数组==,否则异常
# 应用场景
字符数组无法直接被复制
```
char name[20]={0};
name = "zhangsan";
//异常
```
原因是name数组名是地址
地址是一个常量值,不能被赋值
## strcpy常见异常
## 提前遇到'\0',结束打印
```
char name[20] ={0};
strcpy (name,"zhang\0san");
//name中只有zhang
```
## 复制数组无\0,被赋值数组溢出
```
char arr[] = {'a','b','c'};
//源数据数组arr无\0
char name[20] ={0};
strspy(name,arr);
//arr溢出
```
## 接收复制数组大小不够,造成越界
```
char name[3] ={0};
strcpy(name,"zhangsan");
//name越界,导致异常
```
## 接收赋值的数组为常量,目标区域无法修改
```
char* p ="abcdef";
char arr[] = "bit";
strcpy(p,arr);
//异常
//p指向一个常量字符串,常量字符串无法被修改
```
# 模拟实现
```
#include<stdio.h>
#include<string.h>
#include<assert.h>

char* my_strpy(char* dest, const char* sou) {
	assert(dest);
	assert(sou);
	
	char* dest0 = dest;
	//返回dest的拷贝
	
	while (*sou !='\0') {
		*dest++ = *sou++;
		//先复制,后++
		// sou++;
		// dest++;
	}
	return dest0 ;
}

int main() {
	char arr[] = "abcdefg";
	char drr[20] = { 0 };
	char* drr2 = my_strpy(drr, arr);
	printf("%s\n", drr);
	printf("%s\n", drr2);
	return 0;
}
```
