# strlen
```
size_t strlen (const char* str);
```
+ 字符串已经以'\0'作为结束表示,
strlen返回的是在字符串中'\0'前面出现的字符个数,不包含'\0'
+ 参数指向的字符串必须要以'\0'结束
+ sizt_t类型为无符号数

# strlen的返回值
```
#include<stdio.h>
#include<string.h>
int main() {
	if (strlen("abc") - strlen("abcdef") >0)
	{
		printf(">\n");
	}
	else
	{
		printf("<\n");
	}
	return 0;
}
```
返回>
两个无符号数+-,得到的值仍是无符号数
直接比较
```
#include<stdio.h>
#include<string.h>
int main() {
	if (strlen("abc") > strlen("abcdef") )
	{
		printf(">\n");
	}
	else
	{
		printf("<\n");
	}
	return 0;
}
```
# 模拟实现
## 计数器实现方法
```
#include<stdio.h>
#include<assert.h>
size_t my_strlen(const char* arr) {
	assert(arr);
	size_t count = 0;
	while (*arr != '\0') {
		count++;
		arr++;
	}
	return count;
}
// ## 计数器实现方法
```
## 指针运算方法
```
size_t my_strlen02(const char* arr) {
	assert(arr);
	char* arr0 = arr;
	while (*arr != '\0') {
		arr++;
	}
	return arr-arr0 ;
}
//指针 - 指针方法
```
## 递归实现
```
size_t my_strlen03(const char* arr) {
	if (*arr == '\0')
	{
		return 0;
	}
	else
	{
		return (1+my_strlen03(++arr));
	}
```
