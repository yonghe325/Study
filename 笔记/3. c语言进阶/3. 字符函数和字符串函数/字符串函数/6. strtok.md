```
char *strtok( char *str, const char *sep);
```
 寻找 `str` 所指向的 空终止字节字符串中 的 下个记号
  由 `sep` 所指向的空终止字节字符串鉴别分隔字符
此函数被设计为调用多次以从同一字符串获得相继的记号
切割字符串
1. sep
	+ sep 指向 存储分隔符 的 空终止字节字符串
2. str
 +  当str不为空指针时 : 
	+ 调用则被当做 `strtok` 对 `str`指向字符串的 ==首次调用==
		+ 搜索首个 不 含于 `sep` 的字符
			+ 若没有这种字符,则认为 `str` 中==完全没有记号==,
			 返回`NULL`
			+ 若有这种字符 , 则以该字符为 ==记号的起点==,搜索首个不含于`sep`中的字符
				+ 若在`str`中找到存在于`sep`指向字符串中的 字符 : 
					+ 则该字符字符将会被==替换为'\0'==,
						 意味着==str指向的字符串将会被修改==
					+ 并将 被替换字符 的 ==下一个字符的指针==存储于静态位置,
					     为==后续调用==所用
					+ 返回 该记号 起始的指针
				+ 若在`str`中找不到存在于`sep`指向字符串中的记号 : 
					+ 则认为`str`中完全没有记号
					  返回 `NULL`
 + 当str为空指针时 : 
	+ 则将本次调用当做 `strtok` 对 `str` 的 ==后继调用==
		+ 从先前调用中它 剩下的位置开始 搜索 首个 不 含于 `sep` 的字符
			行为类似于将先前存储的指针作为 `str` 传递
			+ 若没有这种字符,则认为 `str` 中 已经没有其他记号
			 返回`NULL`
			+ 若有这种字符 , 则以该字符为 ==记号的起点==,搜索首个不含于`sep`中的字符
				+ 若找到存在于`sep`指向字符串中的 字符 : 
					+ 则该字符字符将会被==替换为'\0'==
					+ 并将下一个被替换字符的下一个指针存储于静态位置,
						==替换上一次调用储存的指针==
					    为后续调用所用
					+ 返回 该记号 起始的指针
				+ 若找不到存在于`sep`指向字符串中的记号 : 
					+ 则认为 剩余`str` 已经没有记号
					  返回 `NULL`
