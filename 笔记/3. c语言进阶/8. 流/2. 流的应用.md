# C程序中的流
任何一个c程序,运行都会打开三种流
+ FILE* stdin : 标准输出流 (键盘)
用于接收用户输入，类似键盘输入这种，默认缓冲方式为行缓冲
即当检测到换行符或缓冲区满时会提交数据
+ FILE* stdout : 标准输入流 (屏幕)
用于输出到屏幕，默认缓冲方式也为行缓冲
+ FILE* stderr : 标准错误流 (屏幕)
用于输出错误信息，一般采取立即输出的方式

以上三种流,其实就是键盘,屏幕对应的 FILE\* 指针
==所有流的类型都是FILE* 类型==

通过改变流,就可以改变输入/输出形式
```
struct S
{
	char arr[30];
	int age;
	float score;
};
FILE* pf = fopen("D:\\c语言，java学习\\Study\\Ccode\\测试文件存放处\\test1.txt", "w");
	struct S s = { "zhangsan",25,50.5f };
	fprintf(pf,"first : %s %d %f",s.arr,s.age,s.score);
	
FILE* pf = fopen("D:\\c语言，java学习\\Study\\Ccode\\测试文件存放处\\test1.txt", "r");
	fscanf(pf, "first : %s %d %f", s.arr, &(s.age), &(s.score));
	
printf("%s %d %f", s.arr, s.age, s.score);
```
上述printf为打印到屏幕
通过改变输出流,就可以打印到屏幕
```
struct S
{
	char arr[30];
	int age;
	float score;
};
FILE* pf = fopen("D:\\c语言，java学习\\Study\\Ccode\\测试文件存放处\\test1.txt", "w");
	struct S s = { "zhangsan",25,50.5f };
	fprintf(pf,"first : %s %d %f",s.arr,s.age,s.score);
	
FILE* pf = fopen("D:\\c语言，java学习\\Study\\Ccode\\测试文件存放处\\test1.txt", "r");
	fscanf(pf, "first : %s %d %f", s.arr, &(s.age), &(s.score));
	
fprintf(stdout,"%s %d %f", s.arr, s.age, s.score);
```
将文件内容格式输出,以stdout标准输入流 (屏幕)的方式,直接打印到屏幕上
