# malloc 开辟内存块
```
void* malloc( size_t size );
```
开辟`size`个字节的==连续==空间
+ 如果`size`为0,则行为未定义
+ 申请成功时,以 `void*`类型 返回起始字节的地址
+ 申请失败时,返回==空指针==
## 内存泄露
malloc申请的内存在使用之后不会自动回收
如果不回收,会导致该内存在==程序运行内==永久被占用,
因而造成内存的泄露
+ 解决方法 : 
	1. 使用free函数释放(解分配)内存
	2. 等待程序运行结束,系统自动回收内存
# free  回收内存
```
void free( void* ptr );
```
释放(解分配)之前由malloc() , calloc() , realloc() 分配的空间
允许系统使用该块内存
+ 若 `ptr` 为空指针，则函数不进行操作
+ 若 `ptr` 的值不等于之前从malloc() , calloc() , realloc() 返回的值,则行为未定义
	+ `ptr`必须指向由malloc() , calloc() , realloc() 开辟的空间
+ 若 `ptr` 所指代的内存区域已经被释放(解分配)，则行为未定义
+ 若在 `free()` 返回后通过指针 `ptr` 访问内存，则行为未定义
	+ 除非另一个分配函数==恰好==返回等于 `ptr` 的值(==极小概率==)
+ `ptr`在==被释放后,仍然指向被分配的首地址==,即还能通过`ptr`使用该地址
	+ 应使用NULL让`ptr`变为空指针,避免野指针

# calloc : 开辟数组内存
```
void* calloc( size_t num, size_t size );
```
为 `num` 个对象的==数组==分配内存,每个对象为`size`个字节
并==初始化所有分配存储中的字节为零==
+ 返回值
	+ 若分配成功,会返回指向分配内存块最低位(首位)字节的指针,它为任何类型适当地对齐
	+ 若分配失败,返回空指针
+ 实际分配大小 : 
	+ 因为对齐需求的缘故，分配的字节数不一定等于 `num*size`
+ 使用案例
```
	int *p1 = calloc(4, sizeof(int));    // 分配并清零 4 个 int 的数组
    int *p2 = calloc(1, sizeof(int[4])); // 等价，直接命名数组类型
    int *p3 = calloc(4, sizeof *p3);     // 等价，免去重复类型名
    
    if(p2) {
        for(int n=0; n<4; ++n) // 打印数组
	        printf("p2[%d] == %d\n", n, p2[n]);
    }
//输出:
//p2[0] == 0
//p2[1] == 0
//p2[2] == 0
//p2[3] == 0
```
# realloc  重新分配内存
```
void *realloc( void *ptr, size_t new_size );
```
重新分配给定的内存区域
+ `ptr`
	+ 当`ptr`指向之前由malloc() , calloc() , realloc() 分配的空间
		且==未被free或realloc的调用所释放==的指针时,该函数的功能为==扩容==
	+ 当`ptr`指向一个空指针时,该函数的功能与malloc相同,为==开辟空间==
	+ 当`ptr`指向其他非以上两种指针时,功能未定义
+ 重新分配 : 
	+ 扩容 : ==新开辟的空间不会初始化==
		+ 情况一 : 原有空间之后==有足够大==的空间
			直接将`ptr`指向的空间向后延伸至`new_size`个字节
			+ 返回原`ptr`
		+ 情况二 : 原有空间之后==没有足够大==的空间
			在堆区重新寻找一个`new_size`个字节的新空间
			将`ptr`指向的空间复制到新的空间
			==然后自动将`ptr`指向的空间释放==
			+ 返回新空间的首地址
	+ 缩小 : 
		+ 内容在新旧大小中的==较小者范围==内保持不变
			类似`ptr`指向的空间从==低地址向高地址==截取`new_size`
			+ 返回`ptr`
		
+ 返回值 : 
	+ 若重新分配失败,则不释放旧内存块,并返回==空指针==
	+ 若重新分配成功,则返回相应的地址
