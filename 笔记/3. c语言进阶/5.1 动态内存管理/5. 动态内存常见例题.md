# 传值调用,传址调用不清晰
```
void GetMemeory(char* p) {
	p = (char*)malloc(100);
}
void Test(void) {
	char* str = NULL;
	GetMemeory(str);
	strcpy(str, "hello,world"); 
	printf("%s", str);
}

int main()
{
	Test();
	return 0;
}
```
+ str为一个char指针,指向NULL
+ GetMemeory以char* p接收 str
	+ 只接收到str的==值==
	+ 类似于
```
void GetMemeory(int p2) {
	p2 = 2;
	//想要将实参p1改为2
}
void Test(void) {
	int p1 = 1
	GetMemeory(p1);
	//传值打印不能实现
	printf("%d", p1);
}
int main()
{
	Test();
	return 0;
}
```
+ 应改为传值调用
```
void GetMemeory(char** p) {
	*p = (char*)malloc(100);
}
void Test(void) {
	char* str = NULL;
	GetMemeory(&str);
	strcpy(str, "hello,world"); 
	printf("%s", str);
}

int main()
{
	Test();
	return 0;
}
```
