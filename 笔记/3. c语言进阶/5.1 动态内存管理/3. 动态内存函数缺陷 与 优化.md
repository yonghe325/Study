# 浪费时间
函数malloc,calloc,realloc,free的执行
均先向系统申请一块在堆区里的空间
然后再返回程序,使用该块内存
而申请需要时间,造成超时
# 内存碎片化
过多的使用函数malloc,calloc,realloc在申请空间
会导致内存成块分布,造成内存块与块之间的小内存空间被浪费
造成内存碎片化,降低内存利用率
# 优化方案
## 内存池
**内存池**是指**程序预先从操作系统申请一块足够大内存**
此后，**当程序中需要申请内存的时候**，不是直接向操作系统申请，而是**直接从内存池中获取**
同理，**当程序释放内存的时候**，并不真正**将内存**返回给操作系统，而是**返回内存池**
**当程序退出(或者特定时间)时，内存池才将之前申请的内存真正释放**
