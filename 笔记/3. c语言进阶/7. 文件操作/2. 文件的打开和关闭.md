# 文件指针
缓存文件系统中,关键的概念是==文件类型指针==
简称==文件指针==
每个被使用的文件都在内存中开辟了一个相应的文件信息区
每个文件信息区斗都与一个文件绑定
用来存放文件的相关信息,例如文件的名字,文件状态,文件的当前位置等
这些信息保存在一个结构体变量中
该结构体类型有系统声明
取名为 
==FILE==
# 文件操作
1. 打开文件
当打开文件时,系统会根据文件类型的情况自动创建一个FILE结构的变量
并填充里面的信息
使用FILE\*来委会这个FILE结构的变量,使用更方便
==打开该文件,其实就代表打开该文件对应的流==
2. 读\写-操作文件
通过文件指针变量,可以找当对应的文件信息区
当操作该文件时,对应的文件信息区会自动改变
3. 关闭\保存文件
