# fopen 
```
 FILE* fopen( const char *filename, const char *mode );|
```
打开 `filename` 所指示的文件,并返回指向关联到该文件的文件流的指针
`mode` 用于确定文件访问模式
+ 返回值 : 
	+ 成功打开 : 返回该文件对应的FILE*
	+ 打开失败 : 返回NULL
## mode
### 无+ 功能不变
+ r : 只读 文本文件
	+ 若文件存在,则文件打开成功
	+ 若文件不存在,则返回 FILE \*p 为 NULL 
	+ 通过此函数,可以判断文件是否打开成功 , 文件不存在 , 权限不足 , 等都会导致文件打开失败
+ w : 只写 文本文件
	+  如果文件存在 , ==覆盖原有数据==重新写入数据
	+ 如果文件不存在,就创建文件
	+ 写出时 , 将==该文件原有数据覆盖== , 即文件长度清 0 , 删除文件内容 , 重新写入文件内容 
+ a : 追加 文本文件
	+ 如果文件不存在 , 则 创建文件
	+ 如果文件存在 , 则新写入的数据会被 ==追加到文件末尾== , 文件==原来的数据会被保留==

# fclose
```
int fclose( FILE * stream );
```
关闭给定的文件流
冲入任何未写入的缓冲数据到 OS , 舍弃任何未读取的缓冲数据。
+ 返回值 : 
	+ 成功时为 ​0​ 
	+ 否则为 EOF 。
