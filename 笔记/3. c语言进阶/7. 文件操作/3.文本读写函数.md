## fgets 文本行输出函数 适用于所有输入流
```
char *fgets( char* str, int count, FILE *stream );
```
从给定文件流读取最多 count - 1 个字符并将它们存储于 `str` 所指向的字符数组
若==文件尾出现==或==发现换行符==则终止分析 , 后一情况下 `str` 将包含一个换行符
若读入字节且无错误发生，则紧随写入到 `str` 的==最后一个字符后写入空字符==
+ 返回值 : 
	+ 成功,返回`str`
	+ 失败时,返回`NULL`

## fwrite 二进制输出 仅适用于文件流
```

```
以二进制的格式,写 `count` 个来自给定数组 `ptr` 的`size`个字节到输出流`stream`
+ `ptr`指向 要写入的元素的 数组
+ `size` 表示一个元素的大小
+ `count` 表示共有几个该元素
+ `stream` 指向要输出的流
+ 样例 :
```
	fwrite(&s, sizeof(struct S), 1, pf);
从&s指向的地址,向取一个结构体S类型所占的字节,输出/写入到pf指向的流
```

## sscanf / sprintf
==不针对任何流==
在 序列化 与 反序列化 中 
常常遇到上述两个函数
### sscanf
```
int sscanf( const char* buffer, const char* format, ... );
```
从 `buffer`指向的字符串获取格式化的数据 , 写入进其他变量中
+ 返回值 : 
	+ 成功时, 返回成功赋值的接收参数的数量
		可以为零，在首个接收用参数赋值 ==后== 匹配失败的情况下
		即第一个参数赋值成功
	+ 失败时, 若输入在首个接收用参数赋值 ==前== 发生失败，则为 `EOF`
		即第一个参数赋值失败
+ 样例 : 
```
struct S
{
	char arr[10];
	int age;
	float score;
};

int main() {
	//sprintf
	struct S s = { "zhangsan",20,55.5f };
	char buf[100] = { 0 };
	sprintf(buf, "%s %d %f", s.arr, s.age, s.score);
	printf("%s", buf);
	
	//sscanf
	struct S tmp = { 0 };
	sscanf(buf,"%s %d %f", tmp.arr, &(tmp.age), &(tmp.score));
	//将buf指向的字符串中 获取格式化的数据放入到tmp中
	
	
	return 0;
}
```
### sprintf
```
int sprintf( const char* buffer, const char* format, ... );
```
将格式化的数据转化成字符串,并写入进 `buffer`指向的数组(字符串)
至多写 `buf_size` - 1 个字符,产生的字符串会以空字符终止，除非 `buf_size` 为零
	若 `buf_size` 为零，则不写入任何内容，且 `buffer` 可以是空指针
	然而依旧计算返回值（会写入的字符数，不包含空终止符）并返回
+ 返回值 : 
	+ 若成功写入 :返回写入到 `buffer` 的==字符数==（==不计空终止字符==）
		+ 若 `buf_size` 为零，则不写入任何内容，且 `buffer` 可以是空指针
			然而依旧计算返回值(会写入的字符数,不包含空终止符)并返回
	+ 或若输出错误或编码错误(对于字符串和字符转换说明符)发生则为==负值==
+ 样例 : 
```
struct S
{
	char arr[10];
	int age;
	float score;
};

	struct S s = { "zhangsan",20,55.5f };
	char buf[100] = { 0 };
	sprintf(buf, "%s %d %f", s.arr, s.age, s.score);
	printf("%s", buf);

//输出
//zhangsan 20 55.500000
```
