# 修改变量类型名称
## 重命名简单类型
```
typedef unsigned int unit;
```
将unsigned int类型 重命名为 unit类型

## 重命名复杂类型
### 函数指针类型
```
typedef void(*)(int) pf_t; // 错误
typedef void(*pf_t )(int); // 正确

pf_t(4) 
//完全等价于
void(*pf_t )(4)
```
将 void(\*)(int) 函数指针类型 重命名为 pf_t类型
