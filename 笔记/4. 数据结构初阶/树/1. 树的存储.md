# 兄弟结点表示法
使用二叉链表形式存储
```
typedef struct Node{
	int data;
	Node* first_chile;//指向该节点的第一个子结点
	Node* next_sibling;//指向该结点的兄弟结点
}Node; 
```
first_chile相当于二叉树的左结点
next_sibling相当于二叉树的右结点
就可以用遍历二叉树的方式,遍历普通树
用操作二叉树的方式操作普通树]

# 父结点表示法
顺序存储,使用数组存放数据
每个结点有如下结构
```
typedef struct Tree{
	int data;//用来存放数据
	int index;//用来存放在数组中的下标
	int parent;//用来存放它的父结点所在的下标
}T;
```
定义一个结构体数组,存放所有结点
==按照某种顺序==,将每个结点放入数组中
将其结点中的index(下标)修改为该结点在数组中的位置
将其结点中的父节点所在的下标(parent)修改为其父结点在数组中的位置(下标)

# 子结点表示法 : 找子结点很容易
顺序存储 + 链式存储
每个结点有如下结构
```
typedef struct child {
	int index;
	child* next;	
}child;

typedef struct Tree{
	int data;//存放数据
	int index;//存放自己所在数组中的位置
	child* child;//使用链表存放每个子结点在数组中对应的下标
}T;
```
定义一个结点数组,按某种顺序存放所有的结点

# 父子结点表示法
每个结点有如下结构
```
typedef struct child {
	int index;
	child* next;	
}child;

typedef struct Tree{
	int data;//存放数据
	int index;//存放自己所在数组中的位置
	int parent;//存放父结点所在数组中的位置 
	child* child;//使用链表存放每个子结点在数组中对应的下标
}T;
```
