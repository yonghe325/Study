# 定义
n(n>=0)的结点构成的有限集合
+ n=0时: ==为空二叉树==
	通常为递归的终止条件
+ n>0时: 有根结点+互不相交的左子树和右子树
	左右子树也是二叉树

# 基本性质
## 叶节点数 = 双分支节点数+1
即$n_0 = n_2+1$ (i表示度为i的结点个数)
+ 解释 :
	+ $n = n_0+n_1+n_2(1)$
		即 总结点数 = 度为0的结点个数 + 度为1的结点个数 + 度为2的结点个数  
	+ 又因为 $节点数n = 边数+1=所有结点度数之和+1$
	+ 所以$n = n_1+2n_2(2)$
	+ 联立(1)(2)得
		$n_0 = n_2+1$
## 二叉树每层最多有$m^(h-1^)$个结点
## 高度为h的二叉树,最多有$2^h-1$个结点
$$\begin{flalign}
&2^0+2^1+2^2+2^3+2^4+2^5+...+2^{h -1}\\
&=\frac{1\times(1-2^h)}{1-2}\\
&=\frac{(1-2^h)}{-1}\\
&=2^h-1\\
\end{flalign}$$
