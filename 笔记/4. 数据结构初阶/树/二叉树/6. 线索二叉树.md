# 概念
根据遍历的顺序,将二叉树的结点串联
此时的二叉树就叫做线索二叉树(Threaded Binary Tree)
线索二叉树根据遍历的顺序的不同分类

而按照某种遍历顺序构建线索二叉树的过程,
被称为==二叉树的线索化==
# 前驱,后继
有二叉树如下
![[Pasted image 20251204135536.png]]
它的中序序列为 : B->D->A->C
此时:
+ 称B的前驱为NULL,后继为D
+ D的前驱为B,D的后继为A
+ A的前驱为D,A的后继为C
+ C的前驱为A,C的后继为NULL
# 线索化
+ 对于叶结点
	让它的==空左结点==指向它的==前驱==
	让它的==空右结点==指向它的==后继==
+ 对于分支节点
	如果他的==右结点为空==,则让它的右结点指向它的前驱
	如果他的==左结点为空==,则让它的左结点指向它的后继
	如果他的==左右结点都不为空==,则不对它进行任何操作
[中序线索二叉树]![[Pasted image 20251204140723.png]][虚线表示指向的是前驱后继]
此时 只靠左右指针 无法区分 一个结点的左右指针究竟是指向 它的子树 还是 它的前驱后继
就需要单独为每个结点做记号,标记它的左右指针指向的是 子树 还是 前驱后继
```
typedef struct TBTNode
{
    int data;
    int ltag;//标记左指针
    int rtag;//标记右指针
    TBTNode * left;
    TBTNode * right;
}TBTNode;
```
当标记为0时,表示指向的是子结点 
当标记为1时,表示指向的是前驱后继
特殊的:
当为处于序列首尾的结点做标记时
由于他们的前驱,后继分别为NULL,且左,右指针也为NULL
规定他们对应的标记设为1,表明他们的前驱后继为NULL

# 遍历
普通二叉树遍历需要占用栈空间
占用的栈空间取决于树的高度
而线索二叉树通过其线索直接遍历
省去了栈空间
