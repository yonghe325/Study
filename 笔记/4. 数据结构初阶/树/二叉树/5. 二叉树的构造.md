# 遍历序列不能唯一
对于同一棵树,相同的遍历顺序一定是相同的
但给出遍历顺序,构造出的二叉树不一定相同
只给出一种遍历序列,不能构造树

# 构造
## (先/后)序列 交叉 中序序列构造
通过 (先序序列 或 后序序列 或 层序序列) 结合 中序序列
可构造出唯一的二叉树
例如: 
先序序列 : A B D G E C F H 
中序序列 : G D B E A C H F
由DLR确定整颗树的根结点为A
由LDR确定A的左边G D B E为A的左子树,A的右边C H F为A的右子树

由DLR确定A的左子树的根结点为B
由LDR确定B的左边G D为B的左子树,B的右边E为B的右子树

由DLR确定B的左子树的根结点为D
由LDR确定D的左边G为D的左子树,D的右边为NULL
依次类推

后序序列 + 中序序列也如此,
层序序列 + 中序序列需要根据中序序列判断层级
