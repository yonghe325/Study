# 散列函数
## 直接定值
当关键字为连续的时候
通过增加偏移,使映射地址连续
不会冲突,但空间有时会大量浪费
+ H(key) = key
+ H(key) = Akey + B
## 除留余数法
当关键字分散时
最常用
+ H(key) = key % p
	p一般取小于等于表长的最大质数
	任何数对p求余,都会小于等于(p-1)
	通过此方法进行映射,将不连续的内容
	放入连续的数组内

# 冲突
冲突会影响散列表的效率
冲突的概率由 装填因子α 决定
α = n(表中元素的个数)/表的长度
α越大,发生冲突的概率越大
α越小,空间利用率越小
## 解决方法
### 开放定值法 :当冲突时,存放到现有表的空位置
+ 线性探测法:
	当冲突时,依次探测下一个位置,直到找到空位置,表尾的下一个是表头
	+ 当查找时,从原来初始对应的下标向后查找
		当查找到空位时,则可确定表中无该数据
	+ 当删除时,为删除位置设置标记,保证该位置不能被检测为空,防止截断
+ 平方探测法:
	当冲突时,按照相对于原位置下标 
		1 -1 4 -4 9 -9 ...的位置进行存放
	+ 当查找时,也按照该方式查找
		当查找到 空位 时,则可确定表中无该数据
	+ 但删除时,同样为删除位置设置标记,保证该位置不能被检测为空,防止截断
	+ 问题 : 
		+ 由于时跳跃探测,有些数据可能不会被探测,导致查找失败
			令 表长 = 某个4k+3的质数,可避免该问题发生
### 拉链法 : 令冲突的元素在同一条链表上
此时,==散列表存放一条单链表的头节点==
当冲突时,将该数据 头插(常用头插)/尾插 入对应链表
# 效率分析
通过 平均查找长度ASL 判断散列表的效率

ASL(成功) = 每个数据的查找次数 / 关键字个数
ASL(失败) = 原有对应下标到距离最近的空位置的长度 / (最大下标+1)
线性散列函数容易造成堆积,造成效率下降
