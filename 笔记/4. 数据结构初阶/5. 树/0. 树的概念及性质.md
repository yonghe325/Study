# 度为m的树 与 m叉树
相同点 : 树中结点的度最多为m
不同点 : 
+ 度为m的树 中,==至少有一个结点的度为m==
+ m叉树 中 ,==所有节点的度都可以小于m,甚至是空树==
# 树的性质
## 结点数 = 总度数 + 1  = 边数 + 1
+ $结点数 = n_1 + n_2 + n_3 + ... + n_m$
	$n_m表示 第m层的结点个数$
+ $所有节点的度数之和 =0n_0 + n_1 + 2n_2 + 3n_3 + ... + mn_m$
	$mn_m表示 第m层的度的个数$
## m 叉树的第i层最多有$m^(i-1^)$个结点
## 高度为h的m叉树最多有$(m^h - 1)/(m - 1)个结点$
+ 每层结点数相加得$$m^0+m^1+m^2+...+m^(h-1^)$$为等比数列
+ 由等比数列通项和得$$\frac {m^h - 1}{ m - 1}$$
## ==具有n个结点的m叉树的最小高度==为$$\lceil \log_m(n(m-1)+1) \rceil$$
+ 解释 :
	+ 因为要求高度最小,所以每一层尽量填满
		1. 假设最小高度为h层![[Pasted image 20251203171039.png]]
			+ 则表明至少第h-1层是满的,且第h层至少有一个结点 ; 至多h层是满的
		2. 由$高度为h的m叉树最多有(m^h - 1)/(m - 1)个结点$得
			+ $$\frac {m^(h-1^)-1}{m-1} +1 \leq n \leq \frac {m^h-1}{m-1}$$
			+ +1去掉,等价为
			$$\frac {m^(h-1^)-1}{m-1}  < n \leq \frac {m^h-1}{m-1} $$
			+ 同乘m-1后+1得
				$$m^(h-1^) < n \leq m^h$$
			+ 取m为底的对数得
				$$h-1< \log_m{(n(m-1)+1)}\leq h$$
				所以
				$$h<\log_m{(n(m-1)+1)}+1$$
				且
				$$h\geq\log_m{(n(m-1)+1)}+1 $$
			+ 所以
				$$\log_m{(n(m-1)+1)}\leq h<\log_m{(n(m-1)+1)}+1 $$
		3. 因为h代表树的高度,所以h一定是一个整数
			![[Pasted image 20251203174201.png]]
			因为$log_m{(n(m-1)+1)}\leq h$,所以使$log_m{(n(m-1)+1)}$向上取整
		4. 得到
			$$\lceil \log_m(n(m-1)+1) \rceil$$

+ 具有n个结点的m叉树的最大高度为n
+ 度为m,具有n个结点的树的最大高度为n-m+1
# 树的定义
树(Tree)是n（n>=0）个结点的有限集。当n = 0时，称为空树
在任意一棵非空树中应满足：
+ 有且仅有一个特定的 称为根的 结点。
+ 当n>1时，其余节点可分为m（m>0）个互不相交的有限集T1,T2,…,Tm
	其中每个集合本身又是一棵树，并且称为根的子树。

树的定义是递归的
即在树的定义中又用到了自身,树是一种递归的数据结构
同时树也是一种分层结构,有如下特点:
+ 树的根结点没有前驱，除根结点外的所有结点有且只有一个前驱
	前驱即为父节点
+ 树中所有结点可以有零个或多个后继
	后继即为子节点
# 树中的基本术语
![[Pasted image 20251203135521.png]]
## 节点关系
+ 祖先 : 父节点到根节点经过的所有节点 
+ 子孙 : 从该节点向下延伸的所有节点
+ 子节点 : 从该节点延伸出的节点
+ 父节点 : 延伸出该节点的节点
+ 兄弟节点 : 父节点除该节点以外的节点
## 度
==对象节点的子节点的个数称为度==
在一棵树中
度的个数 = 所有边的的个数
## 分支节点,叶节点
分支节点 : 度大于0的节点
叶节点 : 度等于0的节点
## 深度,高度,层次
### 树
+ 树的高度/深度:
	树中节点的最大层次/高度
### 节点
+ 节点的层次 : 
	定义根节点为第一层,它的子节点为第二层,以此类推
+ 节点的深度 :
	由根节点向下累加
	即对象节点所在的层次
+ 节点的高度
	由叶节点向上累加
	及 叶节点所在的层次-对象节点所在的层次

## 有序树,无序树
+ 有序树 :
	树中结点的各子树从左到右是 有次序 的,不能互换
	若互换节点位置,则变成一颗不同的树
+ 无序树 : 
	树中结点的各子树从左到右 无次序 的,可以更换位置
	更换位置后,还是原来的树
## 路径,路径长度
+ 路径 :
	两个节点之间路径,由两节点之间的节点构成
+ 路径长度 : 
	两节点路径中,其他节点的个数
