# 链表的概念及结构
## 概念：
链表是一种物理存储结构上非连续,非顺序的存储结构
物理结构 : 在内存中如何存储的

![[061b5ffce79596f4445207f850c0db6e.png]]
## 结构
每个存储结构称为一个节点
每个节点分为两个区域
+ 数据域 : 存储节点的数据
+ 指针域 : 指向下一个节点的地址
```
struct Lklist
{
	int data;
	 Lklist* Node;
};
```
# 链表的赋值
通过传递地址,改变每个节点的 数据域,与指针域
```
int main() {
	LK* plist = NULL;
//此时plist->next = NULL
	
	LKPushBack(&plist,2);
	LKPushBack(&plist,2);
	LKPushBack(&plist,2);

	LKPrintf(plist);
	return 0;
}
```
此时plist为一级指针(LK\*)
指向一个LK结构
## 修改
+ 当形参为LK\*时
代表仅拷贝一个(LK\*)变量
不对实参LK\*变量进行修改
+ 当形参为LK\*\*时
形参指向实参的地址,就可以通过解引用修改实参
```
void LKPushBack(LK** pphead,int x ) {
	LK* newnode = (LK*)malloc(sizeof(LK));
	if (newnode == NULL)
	{
		perror(errno);
		exit(-1);
	}
	newnode->next = NULL;
	newnode->data = x;

//如果*pphead为空,说明此时*pphead指向的节点为头结点
//未初始化
//就不找尾节点
	if (*pphead == NULL)
	{
		*pphead = newnode;
	}
	else
	{
		LK* tail = *pphead;
		while (tail->next != NULL) {
			tail = tail->next;
		}
		tail->next = newnode;
	}
}
```
## 打印
打印不修要改变数据,不需要传递实参的地址
```
void LKPrintf(LK* phead) {
	LK* cur = phead;
	//通过 移动变换]]]指针
	while (cur !=NULL) {
		printf("%d->", cur->data);
		cur = cur->next;
		//指针迭代查找下一个节点
	}
	printf("NULL");
}
```
# 链表的优缺点
## 优点 : 
+ 按需申请空间,不用了就释放空间,(更合理的使用了空间)
+ 头部插入数据,不需要挪动数据
+ 不存在浪费空间
## 缺点
+ 每存一个数据,都要存一个指针去链接后面的数据节点
+ ==不支持随机访问==
	+ 即根据下标访问
