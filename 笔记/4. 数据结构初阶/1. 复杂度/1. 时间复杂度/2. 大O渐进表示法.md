# 意义
用于描述函数渐进行为的数学符号
表示函数的大概执行次数
例如 : 
+ F(N) = N^2 + 2\*N + N 的时间复杂度为
	+ O(N^2)
# 推导规则 
+ 替换常数 : 用常数1表示运行时间中的加法常数
+ 取最高项数 : 在修改后的运行次数函数中,只保留最高项数
+ 化简最高项数 : 如果最高项数不是1,则去除与该项数相乘的常数
+ 结果 : 最后得到结果时间复杂度
+ 规则 : 
	+ 可以为多变量![[时间复杂度.png]]
	+ 当一个算法随着输入的不同,而运行次数不确定时,总是取最坏的情况![[时间复杂度01.png]]极少关注平均情况
	+ 时间复杂度由算法的思想决定
